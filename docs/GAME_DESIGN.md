# 게임 설계 — 폐품로봇 원정대

최초 기록: 2026-09-18 / 최신 콘셉트 반영: 2026-09-23 (Asia/Seoul)

이 문서는 기획 대화의 인계용 기록입니다. **사용자가 명시적으로 선택한 방향**, **제작팀이 제안한 기본안**, **아직 정하지 않은 세부사항**을 구분합니다. 아래 수치는 출시 밸런스나 검증된 흥행 공식이 아닙니다.

**현재 배경은 우주·폐품·조립이며 가제는 폐품로봇 원정대다.** 자원이 고갈되어 멸망에 가까워진 지구가 행성 원정대를 보내 자원을 채굴한다. 플레이어는 현지 폐자원으로 방어 로봇을 조립하고, 몰려오는 외계 생명체나 반란 로봇을 막으며 자원 수거를 마치고 행성을 떠난다. 사용자는 스테이지마다 행성을 공략하는 구조와, 밝고 귀여운 폐품로봇·거칠고 묵직한 우주 생존 분위기를 함께 원한다.

현재 브라우저 버전 `0.10.0-growing-expedition`은 홈 → 챕터 1의 스테이지 선택 → 전투, 전장 위의 뽑기·관리 버튼, 구역별 과밀/채굴기/엔진 방어를 구현한다. 같은 고물 행성에서 1번 순환, 2번 위→아래, 3번 왼쪽→오른쪽, 4번 양쪽→중앙, 5번 십자 진입을 적용한다. 열린 길은 시설 앞에서 끝나고 적은 그 자리에 멈춰 공격한다. 여러 입구로 기존 적 생성 총량을 나눠 보낸다. 엔진은 최대 5개, 일반·배속 연습의 새 원정 참가당 1개 소모, 30분마다 1개 회복한다. 홈의 기동 훈련은 무료 3칸 튜토리얼이며 완료 기록만 저장한다. 챕터 1은 10/12/14/16/20칸, 3/5/7/10/15분 방어로 점차 확장한다. 시작 조합 5개 외에는 단계별 자동 해금 11개와 유료가 아닌 크레딧 연구 4개로 나뉜다. 유료 완충은 서버 구매 검증 연결점까지 있으며 실제 스토어 결제는 미연결이다. 랜덤 빈칸 소환, 선택 재료의 위치를 유지하는 조립, 실제 사거리와 속성별 전투를 유지한다. 과거 삼국지·장수 명칭은 이전 기획의 이력으로 읽는다. 실제 이용자 밸런스와 아이폰의 연출 품질·성능은 아직 검증하지 않았다.

최신 캐릭터 방향: 사용자는 **생활용품 자체에 눈·다리·기계적 특징이 붙은 로봇**을 선택했다. 기본은 라이터·물총·드라이어·제빙기·레이저포인터처럼 기능이 떠오르는 물건, 상위는 화염방사기·물대포·강풍기 등으로 발전시키는 방향이다. 아래 기존 29종 이름과 아트는 현재 구현의 기록이며 이 방향으로의 전체 교체는 아직 구현 전이다. [생활용품 로봇 디자인](plans/2026-09-21-household-robots-design.md)에 확정 사항과 검토 후보를 구분했다.

## 1. 제품 목표와 의사결정 권한

- 아이폰을 우선 지원하는 모바일 게임을 만든다.
- 모티브는 스타크래프트의 메이플 운빨 디펜스와 워크래프트 3의 원피스 랜덤 디펜스에서 느끼는 운·조합·사회적 재미다.
- 사용자는 대박 소환, 랜덤 결과로 조합을 완성하는 판단, 다른 사람과 함께하는 경험을 모두 원한다.
- 혼자 좋은 유닛을 뽑는 것에 그치지 않고, 상대가 알아보고 공동 성과로 이어지는 경험이 중요하다.
- 사용자가 원하는 정식 플레이는 **4인 이상 협동**이다. 가능하면 8인, 그 이상까지 확장하고 싶다고 명시했다. 앞서 제작팀이 제안한 2인 첫 출시안은 이 요청으로 대체한다.
- 사용자는 제작 책임자 역할과 개발·기획·QA 페르소나를 통한 자율적인 제작 결정을 위임했다. 통상적인 구현 결정을 매번 다시 승인받을 필요는 없다.
- 실제 지출, 외부 계정 준비, 공개 배포, 인간 플레이테스터 확보는 필요한 정보와 실행 권한을 별도로 확인한다. 페르소나 의견을 실제 이용자 실험으로 취급하지 않는다.

## 2. 사용자와 합의한 핵심 방향

### 행성 원정과 분위기

- 사용자가 정한 스테이지 목표는 행성에서 자원을 채굴하고, 현지 적의 습격을 폐자원 조합으로 막아 수거를 완료한 뒤 떠나는 것이다.
- 지구의 자원 고갈과 원정의 위험을 배경으로 삼으면서, 친근하고 귀여운 폐품 로봇도 함께 살린다. 둘 중 하나만 선택하도록 다시 묻지 않는다.
- 제작팀의 표현 기본안: 배경은 폐광·버려진 산업 시설·거친 행성, 아군은 식별하기 쉬운 짧은 비율과 표정을 가진 로봇, 전투는 금속 충돌·반동·용접 불꽃으로 무게감을 준다. 이 구체적인 배분은 사용자 선호를 구현하기 위한 제안이며 최종 아트가 아니다.
- 채굴·충전 진행은 완료한 웨이브 비율이다. 착륙 지대·엔진 기지·좁은 협곡·탈출항은 완료 후 보스를 처치하면 탈출하고, 채굴장은 채굴기를 끝까지 보호하면 바로 탈출한다. 고철은 판내 재화, 연구 크레딧은 원정 밖의 해금 재화다. 별도 채굴기 조작·자원 운반·영화적 이륙 연출은 아직 구현하지 않았다.

### 행성별 목표와 시설 방어 (2026-09-23)

사용자는 적 누적 제한 외에도 채굴기·우주선 엔진 방어를 제안했고, **도착한 적이 시설 앞에 멈춰 계속 공격하는 방식**을 선택했다. 시설 체력은 개인별이며 내 시설의 파괴가 동료에게 전파되지 않는다.

| 스테이지 | 배치 수 | 방어·채굴 시간 | 보스 제한 | 클리어 / 패배 |
| --- | ---: | ---: | ---: | --- |
| 1-1 착륙 지대 | 10 | 3분 | 1분 | 방어 후 보스 처치 / 적 35기 이상 5초 또는 보스 시간 초과 |
| 1-2 채굴장 | 12 | 5분 | 없음 | 채굴 완료 / 채굴기 체력 0 |
| 1-3 엔진 기지 | 14 | 7분 | 1분 30초 | 충전 후 보스 처치 / 엔진 체력 0 또는 보스 시간 초과 |
| 1-4 좁은 협곡 | 16 | 10분 | 1분 30초 | 중앙 엔진 보호 후 보스 처치 / 엔진 체력 0 또는 보스 시간 초과 |
| 1-5 탈출항 | 20 | 15분 | 1분 30초 | 탈출선 엔진 보호 후 보스 처치 / 엔진 체력 0 또는 보스 시간 초과 |

시설 앞에서 적은 사라지지 않으며 처치할 때까지 각자 반복 공격한다. 냉동은 도착을 지연하지만 시설을 때리는 속도까지 줄이지 않는다. 시설 파괴와 완료가 같은 틱이면 패배가 우선이다. 후속 스테이지에는 과밀 패배를 중복 적용하지 않는다. 현재 2~5번 시설 체력은 3,500/5,000/7,000/9,000, 일반 적의 초당 피해는 4/5/5/6, 보스 피해는 6배다. 적 성장·생성 간격·수입도 단계별 시험값이며 실제 이용자 밸런스는 미검증이다. 최대 전투 시간은 순서대로 4:00/5:00/8:30/11:30/16:30이다.
### 개인 방어와 공동 스토리

- 각 플레이어는 자신의 라인을 독립적으로 방어한다.
- 다른 플레이어가 내 라인의 적을 직접 공격하거나 대신 제거하는 기능은 넣지 않는 방향이다.
- 별도의 공동 목표는 앞으로 **스토리**라고 부른다.
- 최신 모드 구분에서는 스토리를 협동 전용으로 둔다. 싱글은 행성 방어·채굴·최종 보스 공략에 집중한다. 현재 코드에서는 1인 플레이에도 스토리가 발생하므로 이 구분은 후속 구현 사항이다.
- 각자가 보유한 유닛을 스토리에 지원하고, 성공하면 공통 보상을 받는다.
- 탈주나 불운한 동료 때문에 남은 플레이어의 판이 즉시 종료되는 구조를 피한다.
- 개인 방어 실패 조건과 스토리의 실패·보상 규칙은 구분해야 한다. 스토리 실패가 개인 패배를 자동으로 의미하지 않는 것이 제작팀의 기본안이다.

### 로봇 뽑기와 조립

1. 기본 재료 유닛은 랜덤으로 얻는다.
2. 정해진 조합식과 재료를 사용해 더 강한 유닛을 만든다.
3. 정말 드물게 강한 로봇이 뽑기에서 바로 나오는 대박도 둔다.
4. 시작 조합 5개에서 스테이지 클리어로 11개를 자동 해금한다. 별도 상위 연구 4개는 지정 스테이지 클리어 후 연구 크레딧으로 영구 해금한다.

일반적인 조립은 재료가 갖춰졌을 때 성공하는 확정 조합을 기본으로 한다. 뽑기와 조립 결과가 모두 무조건 랜덤인 게임으로 바꾸지 않는다. 사용자는 소환 기능의 명칭으로 **로봇 뽑기**를 선택했다. 진화·합성은 **조립**, 판내 재화는 **고철**로 표시한다. 서버의 `summon`, `combine`, `gold` 이름은 호환성을 위해 유지한다. 첫 뽑기는 즉시 가능하며 성공한 뽑기부터 개인별 0.7초(서버 7틱)를 기다린다. 실패는 고철·뽑기/배치 난수·대기시간을 소비하지 않으며 조립·판매·강화는 이 대기시간과 별개다. 3·6배속 연습에서는 시뮬레이션 틱에 따라 함께 빨라진다.

### 랜덤 배치와 선택한 위치에서의 조립 — 사용자 지정 방향

- 로봇 뽑기는 **랜덤 위치에 소환**한다. 이전 제작팀의 소환 위치 직접 지정 제안은 이 사용자 결정으로 대체한다.
- 조립 결과는 **사용자가 선택한 재료 로봇의 위치**에 남는다. 조합에 쓰는 여러 재료 중 어느 로봇을 기준으로 선택했는지가 결과 위치를 결정한다. 다른 재료들은 소비되며 그 자리는 비게 된다.
- 따라서 같은 조합이라도 어느 재료를 선택하고 실행하는지에 따라 완성 위치가 달라진다. 조립 경로와 뽑힌 위치를 함께 보고 성장 방향을 결정하는 것이 의도다. 태그 강화와 구분해, 여기서 말하는 업그레이드는 재료를 소비하는 조립이다.
- 현재 구현은 배치 가능한 빈칸에서 균등 추첨하고, 조립 재료 목록의 첫 개체를 사용자가 선택한 기준 로봇으로 검증해 그 자리를 유지한다. 파견된 로봇의 복귀 칸은 점유 상태를 유지한다. 배치 추첨은 유닛 종류 추첨과 별도 난수 상태를 사용한다.

도감의 '위치 선택'은 조립을 즉시 실행하지 않고 재료 로봇의 상세를 연다. 사용자는 기준 재료를 확인하거나 다른 재료 로봇을 선택한 후 조립한다. 자유 이동 기능은 없으며 이동 허용 여부는 별도 미정이다.

### 속성별 전투 역할 — 사용자 지정 방향

| 계열 | 사용자가 제안한 특징 | 위치·전술과의 연결 |
| --- | --- | --- |
| 화염 | 짧은 사거리, 강한 화력 | 적이 가까이 지나가는 구간에서 공격 기회를 확보 |
| 바람 | 강한 스플래시 공격 | 여러 적이 모인 구간의 처리에 강점 |
| 냉동 | 적 이동 속도 감소 | 아군의 공격 구간에서 적이 머무는 시간을 늘리는 역할 |
| 레이저 | 긴 사거리, 단일 대상 공격 | 넓은 구간에서 한 적을 지속적으로 공격 |

본체·무기·발광부·초상·공격 효과는 속성별 공용 팔레트를 따른다: 화염 빨강/주황, 냉동 파랑/청록, 바람 민트, 레이저 보라, 전격 노랑. 생활용품 실루엣과 중립 금속 부품은 남겨 색 이외의 구분도 유지한다.

이 네 역할은 기본 유닛 종류 수나 최종 조합표를 확정한 것이 아니다. 역할별 사거리·피해량·스플래시 크기와 대상 수·감속률과 지속시간은 맵 경로, 적 속도, 시간별 전력 성장과 함께 검증한다. 모든 계열에 같은 공격 형태나 강화를 일괄 적용한다고 가정하지 않는다.

시험 구현은 화염 사거리 160, 바람·냉동 250, 전격 300, 레이저 520의 공통 전장 좌표를 사용한다. 화염 유닛 4종의 공격력을 기존 대비 약 1.8배로 조정했다. 냉동은 일반 적 35%, 보스 15%를 2초간 감속하며 중첩 시 강도가 늘지 않고 지속시간만 갱신한다. 스토리는 정지된 공동 목표이므로 이동 감속을 적용하지 않는다. 상세의 사거리 표시는 짧음·중간·김으로 단순화하고 전장 위에 실제 범위를 그린다. 1번 순환 맵만 세로 화면에서 회전한다. 1번은 420×220, 열린 2~5번은 각각 600×1440·1640×800·1920×880·1440×1440의 전장 좌표를 화면에 투영하며 진입 방향을 유지한다. 길옆 받침대가 배치 칸이고 뽑기 누름 시 빈 칸만 잠깐 밝아진다. 열린 맵의 짧은 가로 화면에서는 로봇과 선택 영역을 함께 축소한다. 수치와 기존 유닛에 배정한 속성은 최종 로스터/밸런스 확정값이 아니다.

### 폐품로봇과 태그 강화

주력 배경은 지구를 위한 행성 자원 원정이며 **폐품로봇 원정대**는 가제다. 현재 고물궤도 전투 프로토타입을 바탕으로 발전시킨다. 제목의 사용 가능 여부나 상표 검토는 완료되지 않았다.

기존 세 축의 투자 구조를 유지하고 표시 명칭을 다음과 같이 바꾼다. 내부 키는 저장 상태·검증 코드·프로토콜과의 호환성을 위해 유지한다.

| 축 | 표시 명칭 | 유지하는 내부 키 |
| --- | --- | --- |
| 계열 | 리사이클 / 오비탈 / 스파크 | `shu` / `wei` / `wu` |
| 형태 | 보행 / 포탑 / 궤도 | `infantry` / `archer` / `cavalry` |
| 특성 | 동력 / 연산 / 제어 | `might` / `strategy` / `command` |

이 분류는 강화 적용과 외형 식별에 쓰는 태그다. 공격 패턴은 `attackPattern`, 속성은 `element`, 사거리는 `attackRange`로 결정한다. 기본 등급부터 속성·범위·감속을 시험할 수 있으며 탱킹은 구현하지 않았다.

| 공격 역할 | 실제 전투 | 판정 |
| --- | --- | --- |
| 집중 사격 (`bolt`) | 사거리 안에서 가장 오래 남은 적에게 기본 공격의 100% | 한 대상 |
| 범위 포격 (`blast`) | 주 대상 80%, 가까운 최대 두 적에 각각 45% | 주 대상에서 115.92 전장 단위 이내 |
| 연쇄 전격 (`arc`) | 주 대상 100%, 다음 두 대상에 45%·25% | 매 연결마다 이전 대상에서 193.2 전장 단위 이내 |

범위 추가 반경 115.92와 연쇄 반경 193.2는 맵 크기가 달라져도 유지한다. 1번 순환 맵에서는 경로를 따른 거리로, 열린 2~5번에서는 경로 번호를 포함한 실제 좌표 거리로 판정한다. 서로 다른 입구의 같은 진행률을 같은 위치로 취급하지 않는다. 주 대상은 로봇 사거리 안에서 고르고, 범위·연쇄 추가 대상은 해당 주 대상/연결 대상과의 경로 거리로 고른다. 동일 거리면 적 ID 순서로 고르며 다른 플레이어 구역으로 넘어가지 않는다. 스토리는 하나의 공동 대상이므로 각 패턴의 주 대상 배율만 적용한다. 상세의 초당 피해는 공격 중 주 대상 이론치로 사거리 밖 대기, 범위·연쇄 추가 피해와 초과 피해를 제외한다. 화염 재료의 상향 후에도 고철거신의 주 대상 공격이 재료 합계 456/초보다 증가하도록 기본 공격 600(주 대상 480/초)으로 조정했다. 이 수치들은 초기 실험값이다.

예를 들어 리사이클·연산 강화에 투자해 고철박사를 노린다면, 리사이클·동력인 볼트타이탄은 계열 강화만 받고 오비탈·연산인 오비탈옵저버는 연산 강화만 받는다. 사용자와 논의했던 삼국지 태그의 부분 중첩 전략을 새 세계관에서도 유지한다.

강화에 맞는 유닛이나 재료를 얻는 것이 그 판의 운과 판단을 연결해야 한다. 강화가 소환 확률 자체를 변경하는 기능은 현재 기본안에 없다.

### 어려운 클리어와 실패

- 목표 로봇을 끝내 완성하지 못해 패배하는 판도 재미의 일부로 허용한다.
- 모든 불운을 보상하거나 매 판 목표 로봇 완성을 보장하지 않는다.
- 클리어 자체에 성취감이 있어야 하며, 반복해서 어려운 판을 깨는 사람을 숙련자로 느낄 수 있어야 한다.
- 사용자는 목표 유닛을 끝내 못 만들 수 있게 하고, 재료 운에 따라 다른 조합으로 전환하는 재미를 살리는 방향을 선택했다. 기존 제갈량 예시는 현재 세계관의 목표 로봇에도 적용한다.
- 여러 승리 조합과 공유 재료·강화 태그를 통해 전환 기회를 설계한다. 대체 조합이 반드시 완성되거나 승리를 보장한다는 뜻은 아니다.
- 특정 로봇 하나가 모든 판에서 유일한 정답이 되는 것은 피한다.

### 모드별 최종 보스 등장 시점 — 사용자 지정 기준

사용자는 싱글 5분·10분·15분, 협동 20분·30분을 버틴 뒤 최종 보스가 등장하는 구조를 기본 설정으로 지정했다. 각 시간은 서로 다른 스테이지/플레이 구성에 적용할 기준이며, 한 판에서 이 시각마다 최종 보스를 연속 소환한다는 뜻은 아니다. 이 내용은 장기 모드의 방향이며, 현재 챕터 1의 시간표는 최신 성장형 원정 설정인 3/5/7/10/15분을 우선한다. 별도 20/30분 협동 모드는 아직 구현하지 않았다.

| 모드 | 방어 시작 후 최종 보스 등장 | 공동 스토리 |
| --- | --- | --- |
| 싱글 | 5분 | 없음 |
| 싱글 | 10분 | 없음 |
| 싱글 | 15분 | 없음 |
| 협동 | 20분 | 있음 |
| 협동 | 30분 | 있음 |

- 지정 시간은 **최종 보스 등장까지의 방어 시간**이다. 성공한 판의 전투 시간은 방어 시간에 실제 보스 처치 시간을 더한 값이며, 최대 전투 시간은 방어 시간에 보스전 제한시간을 더한 값이다. 모드별 보스전 제한시간은 미정이다.
- 이 기준을 바탕으로 시간대별 재화 수입·뽑기 횟수·강화 투자·조합 완성률과 적 성장 곡선을 설계한다. 짧은 판에서도 의미 있는 조합 선택이 가능한지, 긴 판에서는 중간 전환과 상위 조합 계획이 유지되는지 검증한다.
- 뽑기/조합 규칙을 공유하는 방향을 우선 검토하며, 플레이 시간만 늘려 자동으로 난도를 높였다고 판단하지 않는다. 협동의 스토리 보상과 파견 손실, 싱글의 스토리 부재를 각각 경제·전투 측면에서 검증한다.
- 현재 챕터 1은 인원별로 시간을 바꾸지 않으며 위 3/5/7/10/15분 표를 따른다. 채굴장은 5분 보호 후 바로 완료한다. 모드별 장기 시간표와 협동 전용 스토리 분리는 후속 작업이다.

## 3. 제작팀이 선택한 초기 기본안

이 절은 제작팀의 초기 기본안과 현재 구현을 함께 기록한다. 초기 플레이 형식 표의 수치가 위 최신 챕터 1·튜토리얼 규칙과 다르면 최신 규칙을 우선한다. 출시 기준은 실제 플레이 검증 후 정한다.

### 플레이 형식

| 항목 | 초기 기준 |
| --- | --- |
| 인원 | 첫 완성본 4인 실시간 협동. 8인 및 그 이상은 검증을 거칠 확장 목표 |
| 화면 | 가로 화면, 2D 캐릭터, 자동 공격, 고정된 적 이동 경로 |
| 최종 보스 등장 | 현재 챕터 1은 3/5/7/10/15분 방어이며 2번은 보스 없이 채굴 완료. 별도 장기 협동은 후속 범위. 한 원정 안에서 로봇·재료·강화를 유지 |
| 개인 패배 | 1번은 적 35기 이상 5초 유지, 2~5번은 시설 파괴. 보스 스테이지는 보스 시간 초과도 패배 |
| 개인 클리어 | 2번은 채굴 완료, 나머지는 방어 완료 후 개인 최종 보스 처치 |
| 콘텐츠 | 챕터 1의 스테이지 5개와 무료 3칸 기동 훈련. 별도 어려움 난도는 미구현 |
| 사회적 표현 | 대박 소환 알림, 제한된 이모티콘, 친구 초대, 다시 함께 도전 |

개인 패배자는 남은 플레이어를 관전할 수 있다. 동료의 개인 패배가 내 적 수나 개인 패배 조건에 직접 합산되지는 않는다.

내 전장을 크게 표시하고, 나머지 플레이어는 상태 요약·주요 유닛·대박 알림으로 확인하게 한다. 다른 전장과 공동 스토리는 선택해서 자세히 볼 수 있도록 한다. 네 개 또는 여덟 개 전장의 모든 전투를 한 화면에 같은 크기로 배치하지 않는다.

최신 모바일 화면 기준은 **하단의 분리된 정보·조작 띠를 없애고 버튼을 전장에 겹쳐 배치**하는 것이다. 로봇 뽑기는 오른쪽 아래, 로봇·조립·강화는 왼쪽 아래다. 전장은 HUD를 제외한 화면을 채우며 상자를 열어도 크기가 바뀌지 않는다. 선택 로봇의 상세 조립, 도감, 긴 설명은 사용자가 열었을 때만 표시한다. 단순함을 위해 규칙이나 실제 소비 재료를 숨기지는 않는다.

기능을 터치하면 높이 30dvh 이내의 설명·실행 창이 겹쳐 뜬다. 강화는 효과 확인 후 명시적 구매 버튼으로 실행한다. 이벤트는 짧은 배너·대상 강조로 알리고, 전체 조립 경로·연구소는 요청 시 더 큰 대화상자에서 확인한다. 전투 중 자동 확인창을 연달아 띄우지 않는다. 시작은 홈 → 행성 선택 → 전투의 3단계이며 연구소는 홈에서 별도로 연다. 엔진 충전은 별도 대화상자로 연다. 실제 스토어 결제·영구 능력 강화는 아직 구현하지 않았다.

경기 인원은 설정과 플레이어 목록으로 관리한다. 2인 실험은 초기 연결 검증 단계일 뿐 제품 목표를 다시 2인으로 줄이는 근거가 아니다. 8인은 유닛·적 수, 서버 처리, 통신량, 아이폰 표시 성능, 스토리 기여와 매칭을 확인한 후 활성화한다. 8인 이상을 지원한다고 지금 보장하지 않는다.

### 스토리 파견

- 현재 1~5번 스테이지의 스토리 시작 웨이브는 각각 4/7/10, 4/8/12, 5/11/16, 6/12/18, 9/18/27이다.
- 현재 스테이지별 임무 제한은 20/30/35/40/45초이며, 플레이어마다 최대 2기를 **실제로 파견**한다.
- 파견한 유닛은 그동안 개인 방어에서 빠지고, 소유자의 강화 효과를 유지한다.
- 출발 시 원래 배치칸과 보유 한도를 예약한다. 성공하거나 시간이 끝나면 원래 자리로 복귀하며 파견 자체로 유닛을 영구 잃지 않는다.
- 일찍 성공하면 즉시 복귀한다. 개인 패배 시 그 플레이어의 파견 유닛도 스토리 전투에서 제외한다.
- 스토리의 적 체력은 임무별로 고정한다. 불참하거나 탈주했다고 체력을 즉시 낮추지 않는다.
- 정식 4인 기준으로 목표 체력을 조정한다. 좋은 조합을 완성한 플레이어가 부족한 동료의 기여를 메울 수 있게 하되, 어느 인원으로든 성공을 보장하지 않는다.
- 성공 시 그 시점에 개인 방어를 진행 중인 플레이어들에게 같은 판내 재화를 지급한다. 서버상 아직 참가 상태인 일시 단절 플레이어도 동일하게 취급한다.
- 실패하면 추가 보상 없이 개인 방어를 이어간다.
- **조난 신호 구조 → 중앙 전력 복구 → 탈출 항로 확보**로 이어진다. 스토리 시점·체력·제한시간·고철 보상은 현재 방어 시간과 수입에 맞춘 시험값이며 수리나 구조의 별도 조작은 구현하지 않았다.

실제 파견과 분신 파견 중 사용자가 직접 선택한 것은 아니다. 실제 파견은 제작팀이 전력 배분의 긴장감을 위해 채택한 기본안이다.

### 유닛, 소환, 강화

- 기본 9종, 개조 9종, 특급 6종, 전설 4종, 궁극 1종의 총 29종을 구현했다. 궁극은 기존 렌더러와의 호환성을 위해 rarity='legend', tier='ultimate'를 사용한다.
- 확정 조합식 20개를 구현했다. 기본→개조→특급→전설→궁극의 공유 재료 경로를 제공한다. 고철거신은 1-4 클리어로 자동 해금된 뒤 연구 크레딧 없이 만들 수 있다.
- 초기 소환 분포 후보는 기본 93%, 정예 6.8%, 영웅 0.2%다. 전설은 조합으로만 만드는 기본안이다.
- 직접 소환과 조합으로 얻은 동일 유닛의 성능은 동일하다. 직접 소환의 이득은 재료와 시간을 아끼는 것이다.
- 계열·형태·특성 세 축을 첫 버전에 포함한다. 내부 필드명 `faction`·`troop`·`trait`은 유지한다.
- 로봇은 각 축에서 주분류 하나를 갖는다. 현재 29종의 표시 이름과 조합식은 `shared/content.json`이 기준이며, 기존 유닛·조합 ID는 그대로 사용한다.
- 강화는 종류마다 최대 5단계, 단계당 공격력 10%를 더하는 수치에서 검증을 시작한다. 여러 강화의 보너스는 곱하지 않고 합산한다.
- 소환과 강화는 같은 판내 자원을 사용하며, 판내 유닛·자원·강화는 다음 판에 초기화한다.
- 강화 화면에서 선택한 유닛에 적용되는 분류를 강조하고, 조합 화면에 필요한 재료와 현재 보유량을 표시한다.

위 수치는 밸런스 작업의 시작점이다. 공격 외 지원 역할의 강화 적용, 소환 비용, 수입, 개별 유닛 능력치와 스킬은 별도 데이터 설계가 필요하다.

### 영구 해금과 난도

- 시작 시 볼트가드·캔스캐너·렌즈아이·궤도램·충전대장 조합 5개만 사용할 수 있다. 잠긴 조합은 서버도 거절한다.
- 1-1 클리어 후 개조 4개, 1-2 후 특급 3개, 1-3 후 특급 3개, 1-4 후 고철거신을 자동 해금한다. 자동 조합은 연구소에서 구매할 수 없고 기존 클리어 기록에서도 복원한다. 반복 클리어로 중복 지급하지 않는다.
- 아크캐리어는 1-3 후 60, 오비탈마더는 1-4 후 100, 스타라이트코어와 성운방주는 1-5 후 각각 160/240 연구 크레딧으로 선택 구매한다. 현금으로 연구 크레딧을 얻는 기능은 없다.
- 다음 스테이지는 이전 스테이지 클리어로 연다. 현재는 행성별 난도가 다르며 별도 어려움 난도 선택은 아직 구현하지 않았다.
- 각 단계는 시작 조합과 이전 스테이지에서 얻은 자동 조합만으로 첫 클리어를 노릴 수 있어야 한다. 연구 4종 없이 실행한 고정 자동 전략에서 각 단계의 클리어 사례를 확인했으며 사람의 승률이나 모바일 조작 부담을 검증한 것은 아니다.
- 반복 클리어 때마다 신규 유닛을 무한히 추가하는 방식은 채택하지 않는다.
- 영구 공격력 성장과 유료 확률 상승은 첫 버전에 넣지 않는다.
- 최고 클리어 전장·난도와 해당 클리어 횟수를 보여주고, 기록에는 당시 콘텐츠 버전과 해금 상태도 남긴다.

홈의 기동 훈련은 엔진 없이 재입장할 수 있는 별도 3칸·1인 튜토리얼이다. 정해진 로봇을 뽑아 선택·사거리 확인, 세 칸 채우기, 판매, 재뽑기, 선택한 로봇 자리에서의 조립을 연습한다. 준비 버튼 후 8초가 지나 보스가 나오고 60초 안에 처치한다. 훈련은 완료 여부만 기록하며 재화·연구·스테이지 클리어·엔진 보상을 주지 않는다. 강화·파견은 이번 훈련에 포함하지 않는다. 사용자는 **첫 스테이지는 배우며 클리어할 만하게, 이후부터 실패 위험을 크게 높이는 방향**을 선택했다. 첫 스테이지도 무조건 클리어시키거나 특정 유닛을 보장하는 뜻은 아니다. 구체적인 적 구성·성장 곡선·목표 클리어율은 별도 밸런스 검증으로 정한다.

### 이탈과 매칭

- 개인의 일시 단절 동안 기존 유닛은 서버에서 자동 전투를 계속한다. 새로운 소환·조합·강화를 자동으로 대신해주지는 않는다.
- 120초 이내 재접속 시 기존 참가자에게 현재 전투 상태를 복구한다. 그 전에 개인 패배 조건이 발생하면 그대로 패배 처리한다.
- 120초를 넘기거나 명시적으로 나가면 해당 플레이어를 탈주 처리한다. 남은 플레이어의 판은 유지한다.
- 공개 매칭과 친구 초대를 제공한다. 정식 경기는 4명이 모인 뒤 시작한다. 60초 동안 인원을 채우지 못하면 계속 기다리기 또는 표시된 연습 모드를 선택하게 한다.
- 연습은 같은 전투 규칙을 사용하지만 정식 협동 클리어·영구 해금·공개 성취에는 반영하지 않는 기본안이다.
- AI를 실제 플레이어로 위장하지 않는다. 첫 버전에 중도 새 사람 교체나 복잡한 탈주 제재는 넣지 않는다.

### 2026-09-21 구현된 보상과 조합 전환

기본 속도 원정의 개인 결과는 종료 시 한 번 확정한다. 전투에 투자하고 적을 처치한 플레이어는 채굴 구간별 연구 크레딧을 받으며 클리어하면 보너스를 받는다. 이탈과 무입력은 연구 보상을 받지 않고, 배속·연습은 연구·행성·전적 정산에서 제외한다. 목표 조립 실패를 확정 보상으로 대체하지 않는다.

전설 3개와 궁극 1개의 설계도는 연구소에서 가격·선행 행성 클리어·재료 경로를 확인하고 크레딧으로 구매한다. 중복 구매나 결과 재요청으로 재화가 중복 처리되지 않는다. 영구 진행은 로컬 HTTP 서버에 구현됐으며 운영용 계정·Nakama 진행 이식은 별도다.

판매는 선택한 자기 로봇 한 기를 소모하고 그 로봇에 누적 투자한 뽑기 비용의 35%를 내림하여 돌려준다. 조립하면 재료들의 투자비가 합산되고 파견 중 로봇은 판매할 수 없다. 선택창에서 ‘판매’를 누르면 대상 이름과 회수 고철을 확인하며, 명시적으로 확정할 때만 처리한다. 취소·다른 유닛 선택은 판매하지 않는다. 내부 행동은 기존 `salvage`를 사용한다. 고티어 뽑기로 얻은 로봇을 반복 판매해 재화를 늘릴 수 없다.

## 4. 첫 버전의 제작 범위

포함: 튜토리얼, 개인 방어, 확정 조합, 희귀 직접 소환, 태그 강화, 공동 스토리, 매칭·초대, 재접속, 해금 저장, 클리어 기록, 기본 설정과 계정 관리.

첫 버전에서 제외: 대전, 길드, 자유 채팅, 시즌패스, 광고, 결제. 우선 무료 테스트·출시를 목표로 전투와 협동을 검증한다. 이후 수익화 후보는 전투력에 영향을 주지 않는 외형·등장 연출·이모티콘의 확정 구매이며, 아직 구현하거나 확정한 상품은 없다.

## 5. 창작과 권리 원칙

- 원랜디와 메운디에서 일반적인 설계 원리를 참고하되, 조합 관계·진행·화면·연출을 캐릭터만 바꿔 재현하지 않는다.
- 원피스·메이플스토리·워크래프트·스타크래프트의 코드, 맵 파일, 캐릭터 그림, 모델, 음성, 음악, 대사를 가져오지 않는다.
- 우주 폐품로봇의 디자인·명칭·스토리 구성은 독자 제작한다. 기존 로봇 프랜차이즈나 이전 삼국지 아트를 새 콘셉트의 원본처럼 사용하지 않는다.
- 외부 자산을 쓰면 출처와 상업적 이용 조건을 기록한다. 제목과 최종 결과물의 권리 검토는 별도 작업이다.

관련 판단 기준: [대법원 2017다212095](https://www.law.go.kr/LSW/precInfoP.do?precSeq=208504), [저작권법 제5조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1027063057).

## 6. 아직 명세가 필요한 부분

- 현재 29종·20개 조합식·태그 이후에 도입할 실제 능력 차이와 전장별 적 구성. 현재 단일·범위·연쇄 공격을 제공하며 스테이지별 수입·적 성장 수치를 시험하고 있다.
- 현재 데이터에 정의된 판내 수입·뽑기 비용·강화비·스토리 보상량과 확률의 실제 이용자 밸런스 검증.
- 친근한 폐품로봇과 거칠고 묵직한 우주 생존 분위기를 결합한 최종 아트 및 실기기 가독성. 가로 2D는 제작팀의 현재 기본안이다.
- 첫 스테이지 학습 난도와 이후 높은 실패 위험을 구현할 수치, 기준 아이폰 모델과 지원 OS 하한.
- 웨이브에 연결된 현재 채굴 진행 이후의 별도 채굴기 조작·자원 운반과 이륙 연출. 개인 생존·스토리 보상·탈출 판정의 사람 플레이 검증.
- 8인과 그 이상의 활성화 시점, 해당 인원의 스토리 밸런스와 실제 기기·서버 한계.
- 사용자는 Mac mini를 보유한다. 모델·칩·메모리·macOS·개발 도구 설치 상태, Apple 개발자 계정과 서버 예산은 아직 미확인이다.
- 정식 출시 명칭과 실제 이용자 테스트 결과.

통상적인 게임·구현 설계는 위임된 범위에서 제작팀이 구체화한다. 계정·기기·비용 같은 외부 사실은 추측으로 확정하지 않는다.
