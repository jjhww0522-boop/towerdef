# 반복 개발 결과 — 2026-09-20

## 플레이 방법

`npm ci` 이후 `npm run dev`를 실행하고 브라우저에서 `http://127.0.0.1:7351`을 연다. **새 연습 시작**으로 플레이한다. 다른 브라우저 프로필에서 같은 방 코드를 입력하면 최대 4개의 독립 접속으로 연습할 수 있다. 3·6배속은 빠른 흐름 확인용이며 기본 속도는 1배속이다.

## 구현과 수정

- 서버 권위 전투를 사용하는 실제 브라우저 소환·조합·태그 강화·스토리 파견·관전·결과·재도전.
- 같은 요청 재전송의 중복 소비 방지, 실제 시간 기준 단절 유예, 만료 직후 재접속 경쟁 조건 처리.
- 새 원화·투명 캐릭터와 전장, 카드 초상, 서버 공격 시점에 연결한 전투 연출. 표현 범위는 [화면 품질 기록](VISUAL_QUALITY.md)을 참고.
- 조합·강화 패널이 동일한 상태 갱신마다 다시 생성되어 초점이 사라지는 문제 수정.
- 카드 초상과 전장 캐릭터의 병종 선택 규칙 불일치 수정.
- 반복 이동 경로의 입구 통과 시 적이 역방향으로 보간되는 문제 수정.
- 모바일 600×700 세로 전장과 6열 병력 배치, 44px 주요 터치 영역·고정 조작부와 화면 넘침 검증.
- 로컬 의견 저장과 JSON 내보내기. 외부 전송·실제 이용자 모집은 수행하지 않았다.

## 검증 증거

명령은 저장소 루트에서 실행한다. 브라우저 명령은 로컬 서버가 실행 중이어야 한다. Windows에서 검증용 Chrome이 없으면 `npx agent-browser install`을 먼저 실행한다. 기존 Chrome을 지정할 때는 `CHROME_PATH` 환경 변수를 사용한다.

| 명령 | 검증 범위 |
| --- | --- |
| `npm test` | 콘텐츠, 권위 전투, 서버 인증/입장, 단절 유예, 공격 신호, 렌더러 상태 회귀 |
| `npm run test:browser` | 첫 화면, 소환·강화, 재접속, 모바일 넘침, 독립 브라우저 4접속 |
| `npm run test:quality` | 자산 로딩, 실제 UI 조합, 응답 유실 재시도, 모바일 터치, 초점 유지, 의견 내보내기 |
| `npm run test:network` | 실제 localhost HTTP 연결의 4개 자동 참가자와 연결 장애 |
| `npm run simulate -- --compare` | 같은 난수 조건의 자동 전략 비교 |

네트워크 검증은 실제 시간 약119초 동안 17개 검사를 통과했다. 한 명의 명시적 이탈 이후 나머지 셋이 클리어했으며, 다른 한 명은 30초 단절 뒤 기존 병력과 요청 순번을 유지해 복귀했다. 응답을 잃은 요청을 같은 순번으로 보내도 두 번 소비되지 않았다. 자세한 실행 자료는 `artifacts/network-playtest.json`에 있다.

전체 회귀 테스트 51개와 브라우저 기본 검사 8개가 통과했다. 품질 검사 18개도 통과했다. 검사 도구에서 상태 조회 차단이 소환 클릭보다 먼저 발생하던 경쟁 조건을 수정한 뒤 단독 재실행해 확인했다. 자료는 `artifacts/browser-report.json`, `artifacts/browser-quality-report.json`과 `artifacts/quality-desktop.jpg`, `artifacts/quality-mobile.jpg`에 기록된다. 자동 검증 입력은 실제 사람의 의견이 아니다.

## 밸런스 실험

기존 수치는 단순 소환만으로도 거의 모두 성공했다. 전략의 차이를 드러내기 위해 웨이브당 적 체력 증가를 50, 최종 보스 체력을 180000으로 조정했다. 본 실험 80개 라인에서 강화 전략은 60개, 파견을 병행하는 전략은 66개가 성공했다. 별도 난수 80개 라인에서는 각각56개·67개가 성공했다. 상세 조건과 실패한 후보는 [밸런스 반복 기록](BALANCE_ITERATIONS.md)에 있다. 이는 승률 측정이며 재미나 소비자 만족도 측정이 아니다.

## 아직 검증하지 않은 것

- 실제 Nakama 서버 런타임·인터넷 환경에서의 4인 경기.
- Unity 프로젝트 컴파일, iPhone 빌드와 실제 터치·발열·지속 프레임.
- 계정, 영구 진행·해금, 결제, 스토어 배포.
- 실제 소비자의 반응과 지불 의향. 실제 테스트 참가자는 0명이다.

로컬 화면과 자동 검증이 좋아졌다는 사실을 출시 완료 또는 상용 게임과 동등한 품질의 증거로 확대하지 않는다. 비용·계정·공개 배포 작업은 수행하지 않았다.
