# 초반 전투 압박·강화·그림·2구역 화면 개선

대상: `0.13.1-casual-pressure`. 사용자 제보는 강화 이름 불일치, 1구역 적의 즉시 사망, 투박한 그림, 2구역의 좁고 겹치는 화면이다. 자동 검사·에이전트 조작 결과이며 실제 이용자 조사나 휴대폰 실기기 검증이 아니다.

## 전투와 강화

강화는 화염·물·냉기·바람·전기·레이저 여섯 종류로 통일했다. 같은 속성의 모든 단계와 이후 소환/조립한 로봇에 적용한다. 단계당 +10%, 최대 5단계, 비용 40/60/90/130/180을 유지한다. 공통 S는 여섯 강화 중 가장 높은 단계 하나를 적용하고 합산하지 않는다. 웹·서버가 `shared/upgrade-model.js`를 공유하고 C# 모델도 같은 계약을 따른다. 이전 9개 키의 요청은 거절한다.

1구역은 난이도 1, 시작 60고철, 소환 20고철, 일반전 120초 + 보스 최대 60초를 유지한다. 기본 적 체력 18→70, 웨이브당 증가 6→12, 제곱 증가 계수 0.1→0.2, 기본 등장 간격 1.5→1.2초, 최소 간격 1.3→1초로 조정했다. 처치/웨이브 보상과 1구역 보스 체력 4,800은 유지했다.

독립 기획·밸런스팀은 동일 난수 1–20, 1초 간격 입력, 조합+강화·판매 없음·지원/현장개조 없음 조건을 비교했다. 죽은 일반 적 기준 생존 시간이며 미처치 적 수와 결과도 함께 기록했다. 등장 틱에 태어나 바로 죽은 적까지 추적해 평균에서 빠지지 않게 했다.

| 측정 | 변경 전 | 최종 |
| --- | ---: | ---: |
| 적 등장→사망 평균 | 0.37초 | 3.15초 |
| 첫 피격→사망 평균 | 0.31초 | 2.06초 |
| 적이 없는 일반전 시간 | 79.09% | 8.47% |
| 등장한 바로 그 틱의 사망 비율 | 약 57.9% | 약 0.96% |
| 평균 생존 적 수 | 0.24 | 2.57 |
| 조합+강화 성공 | 20/20 | 19/20 |

최종 조합만 정책은 18/20, 막힌 자리를 판매해 다시 뽑는 정책은 20/20이다. 2초 간격의 느린 입력은 조합+강화 19/20, 30초 오판매를 더하면 18/20이며 판매 회복 정책은 두 조건 모두 20/20이다. 일반전에서 적이 쌓이다 조립으로 정리되는 변화를 의도했다. 위 성공률이 실제 초보자 성공률이나 재미 점수는 아니다.

9분류에서 6속성 강화로 전환하면서 중첩 화력이 낮아지는 후반 회귀를 발견했다. 3/4/5구역 보스 체력을 25,500/38,000/90,000에서 19,500/28,500/58,000으로 보정했다. 같은 5개 시드의 판매 회복 정책은 각각 4/5·5/5·3/5다. **5구역의 판매 없는 정책은 0/5(시설 파괴 4, 보스 시간 초과 1)**로 재료 정체와 시설 방어 문제가 남아 있다. 챕터 전체 밸런스가 완료된 패치로 평가하지 않는다.

재현 자료: `artifacts/opening-pressure-2026-09-27/QA_PRESSURE_REPORT.md`와 같은 폴더의 측정 스크립트·개별 결과. 후보/변경 전/실수/최종 포함 1,500판, 최종 실제 콘텐츠 재검사는 140판이다. 강화 독립 검사는 피해 75조건·구매 30회·잘못된 키 10개를 포함한다.

- 실제 HTTP 네 클라이언트 검사 21개 통과. 응답 유실 후 재전송·이탈·30초 통신 중단/복귀·전투 종료를 확인했다. 최종 2명 승리·1명 보스 시간 초과·1명 이탈이며 전원 승리를 요구하는 밸런스 검사가 아니다.

## 캐릭터와 전장 화면

25종 아군·5종 적의 벡터 원본을 둥근 몸체·크림색 얼굴·눈과 볼·속성별 밝은 색으로 다시 그렸다. 작은 유닛끼리도 노즐·뚜껑·팬·냉각고·전극·렌즈의 실루엣으로 구별하도록 했다. 준비→발사→회복 표정과 부품 움직임, 공격 반동, 작은 대기 움직임을 넣었다. 움직임 줄이기 설정에서는 장식 움직임을 제한한다. 외부 자산이나 AI 비트맵을 사용하지 않은 직접 작성 SVG이며, 웹과 모바일 출력의 아군·적 원본을 통일했다.

현재 계약 `mobile-art-3-cartoon`의 PNG530개·WAV11개를 실제로 디코딩했고 빈 그림·잘림·오디오 무음/클리핑을 검사했다. 라이터 뚜껑 잘림과 물총/포인터 발 연결은 검사 중 수정했다. [48/64픽셀 그림](../../assets/mobile-art/game-size-sheet.png), [모션판](../../assets/mobile-art/motion-sheet.png), [제작 출처](../../assets/mobile-art/PROVENANCE.md). 현재 계약 PNG+WAV 파일 합계9.17MiB이며 설치 용량이나 실행 메모리 수치는 아니다.

2구역의 실제600×1440 좌표, 12칸, 경로 길이1360과 사거리 판정은 그대로다. 세로에서는 전장이 차지하는 공간을 확대하고, 가로에서는 같은 좌표를 6열×2행으로 돌려 보여준다. 390px 화면의 기본 유닛 표시 높이는45.5→51.87px, 667px 가로에서는26.68→46.69px다. 더 작은568px 가로에서도 실제 화면 비율로 방향을 결정하고 최소42px를 확보한다. 이 값은 투명 여백까지 포함한 스프라이트 높이이며 실제 몸체 픽셀이나 모든 터치 목표의44×44 보장을 뜻하지 않는다.

바닥·받침대·적 통로의 명암을 분리하고, 세로 통로의 적은 ID에 따른 작은 좌우 간격을 둬 겹침을 줄였다. 실제 공격과 사망의 효과 위치도 같은 표시 좌표로 맞췄다. 짧은 세로 화면의 중복 지원 설명은 숨기고 작은 가로 화면의 지원 버튼은 하단 가운데로 옮겨 유닛을 가리지 않게 했다.

실제 1배속 2구역에서도 소환·물/냉기/레이저/전기 조립 4회, 세로↔가로 회전, 4분 방어 성공과80크레딧 저장을 확인했다. 소환 버튼은1.5초 간격 UI 자동 클릭을 보조로 사용하고 조립은 에이전트가 직접 선택했다. 강화·현장개조·지원·판매·파견은 쓰지 않았다. 148처치·피해25,020·최대 적26·시설 피해0이며, 이 한 판을 전체 난이도의 근거로 삼지 않는다. `artifacts/opening-pressure-2026-09-27/stage2-live-*.png`.
