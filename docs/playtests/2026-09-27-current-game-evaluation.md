# 현재 게임 테스트와 대장 평가 — 2026-09-27

## 결론

**제작 중인 시제품으로는 핵심 기능이 동작하지만, 현재 상태로 유료 출시를 권하기는 어렵다. 주관적 종합 평가는 5/10이다.** 가장 큰 이유는 기능 오류보다 전투 중 판단의 필요성과 성장의 지속성이 약하기 때문이다. 점수는 실제 소비자 평점이나 통계 지표가 아닌, 아래 관찰에 근거한 AI 평가다.

평가 대상은 실행 콘텐츠 `0.12.0-field-mods`의 **5구역·29유닛·20조합**이다. 최근 정리한 6속성별 4단계 + 공통 S의 25종은 설계 문서이며 이번 실행판에는 반영되지 않았다. 따라서 새 성장표의 재미를 검증한 결과가 아니다.

## 수행 범위

- 대장: 새 격리 계정, 로컬 서버 7353, PC Chrome에서 화면을 보고 버튼과 전장 유닛을 직접 선택했다. 무료 훈련을 완료하고 1구역 일반 1배속 전투에서 조립·강화·지원·현장개조를 사용해 승리했다. 보상 저장·연구소 이동·2구역 해금을 확인하고, 2구역도 일반 1배속에서 소환만으로 승리했다.
- 시각 확인: 390×844 세로 화면을 주로 사용하고, 667×375 가로 및 1440×900 데스크톱 화면을 추가 확인했다. 휴대폰 크기를 흉내 낸 PC 브라우저이며 실물 휴대폰 검증이 아니다.
- QA·플레이테스트팀: 빌드와 전체 자동 검사, 훈련·조합 위치·화면 회전·현장개조 흐름 검사.
- 기획·밸런스팀: 현재 코어로 초반 2구역 × 6행동 방식 × 20난수 조건 = **240판** 모의 전투. 여기서 난수 조건(seed)은 뽑기 등 무작위 결과를 동일하게 재현하기 위한 번호다.
- 게임 소스·능력치·기존 사용자 계정은 변경하지 않았다. QA 서버는 메모리 저장소, 대장 서버는 `artifacts/evaluation-2026-09-27/profiles`의 별도 저장소를 사용했다.

## 자동 전투의 핵심 결과

각 칸은 같은 행동 방식으로 난수 조건 1~20을 실행한 성공 횟수다. 현재 상위 직접 뽑기 확률도 그대로 사용했다. 계정 연구·지원 스킬·파견은 사용하지 않았으며, 마지막 방식에서만 현장개조를 선택했다. 봇은 조합식을 즉시 알고 읽는 시간 없이 행동하므로 초보 플레이어의 승률로 해석하면 안 된다.

| 행동 방식 | 1구역 | 2구역 |
| --- | ---: | ---: |
| 아무 조작 없음 | 0/20 | 0/20 |
| 소환만, 자리 가득 차면 대기 | 2/20 | 20/20 |
| 가능한 조합 + 소환 | 19/20 | 20/20 |
| 조합 + 강화 + 만칸 판매/재소환 | 20/20 | 20/20 |
| 조합 + 강화, 판매 안 함 | 20/20 | 20/20 |
| 위 방식 + 선제 센서 | 20/20 | 20/20 |

### 가장 큰 문제: 2구역에서 판단할 필요가 약함

소환만 한 20판은 모두 **32초에 12칸이 찬 뒤 208초 동안 아무 입력 없이, 채굴기 피해 0으로 4분을 통과**했다. 평균 잔액은 **854.7고철**, 범위는 840~897이다. 한 번 소환에 20고철이므로 약 43번 더 뽑을 돈이 남지만 칸이 없어 소환할 수 없다.

이는 돈을 많이 주는 문제와 함께, 재료가 맞지 않을 때 성장하는 방법과 추가 행동의 필요성이 약한 문제다. 조합·강화를 열심히 하는 방식도 시설 피해·완료 시간에서 차이를 보이지 못했다. 단순히 수입만 줄이면 재료를 못 모으는 시간이 더 길어질 수 있다.

별도로 대장이 브라우저에서 1배속 정상 진행으로 12기까지 소환하고, 조합·강화·지원·현장개조·파견을 사용하지 않은 한 판도 성공했다. 결과는 **처치 147, 본진 피해 15,434, 시설 받은 피해 0, 연구 크레딧 +80**이었다. 난수 고정 20판과 별개의 브라우저 관찰이며 무작위 시드는 지정하지 않았다. 판 중간에 화면 크기 변경과 스크린샷 촬영만 했다. [소환 완료 화면](../../artifacts/evaluation-2026-09-27/26-stage2-filled.png), [후반 시설 100% 화면](../../artifacts/evaluation-2026-09-27/30-stage2-idle-late.png), [소환만으로 승리한 결과](../../artifacts/evaluation-2026-09-27/31-stage2-result.png).

### 1구역에서는 조합의 이점이 있지만, 보스에서 갑자기 결과가 갈림

소환만 한 20판은 일반 방어를 모두 통과했으나 18판이 보스 시간 초과로 실패했다. 조합을 알면 19판, 강화까지 쓰면 20판이 성공했다. 필요한 행동이 효과를 낸다는 점은 긍정적이다.

다만 조합+소환의 seed 1에서는 13초에 첫 조합, 20초에 마지막 소환 후 재료가 맞지 않아 더 조합하지 못했다. 끝에 **519고철을 남긴 채 보스 HP 392.4/6400으로 실패**했다. 강화라는 해결 수단은 있었지만 해당 방식은 사용하지 않았다. 초보가 이 상황에서 무엇을 해야 할지 화면에서 알아챌 수 있어야 한다.

소환만으로 성공한 두 판에는 정예/영웅 직접 뽑기가 있었다. 따라서 일반 방어의 여유만 보고 첫 스테이지가 항상 쉽다고 판단하거나, 특정 뽑기 성공을 초반 난도의 전제로 삼으면 안 된다.

## 화면을 조작하며 확인한 점

### 유지할 장점

- 홈 화면의 폐품 로봇 분위기와 큰 시작 버튼은 방향이 읽힌다.
- 훈련은 소환 후 실제 자동 공격을 먼저 보여 주고, 읽는 단계에는 전투를 멈춘다. 판매·재료 확보·조립·보스 처치까지 막힘 없이 진행했다.
- 유닛 선택 정보창이 고정 위치에 열리고 부족한 재료와 조립 위치를 알려 준다. 전투에서 직접 유닛을 눌러 조립 정보를 확인했다.
- 1구역에서 분산 노즐을 고른 뒤 보스 구간에 추적 회로로 바꿀 수 있었다. 전투 결과에는 분산 노즐 추가 피해 33.3, 추적 회로 146.6이 구분되어 나왔다. 효과 선택과 결과 기록이 연결되어 있다.
- 1구역 직접 조작 결과는 처치 78, 최대 적 수 7, 본진 피해 9,992, 과부하 1회, 연구 크레딧 +40의 승리였으며 기록 저장과 다음 구역 해금을 확인했다. 이는 대장 1회의 조작 결과이지 사람의 평균 성적이 아니다.

### 개선할 부분

1. **전투 가독성:** 가독성은 화면만 보고 적·아군·공격·위험을 알아보는 쉬움이다. 390px 세로 화면에서 전투 로봇은 홈의 로봇보다 작고, 667px 가로에서는 여러 로봇과 적의 표시가 더 조밀하다. 새 상위 로봇 그림만 추가하기보다 몸체 크기·계열 실루엣·적 겹침·피해 숫자를 함께 조절해야 한다.
2. **강화 선택의 설명:** 첫 화면에 리사이클·오비탈·스파크·보행·포탑·궤도·동력·연산·제어의 9개 분류가 함께 나온다. 상세를 열면 ‘내 로봇 몇 기에 적용’이 보이지만, 목록에서 어느 강화가 내 병력에 도움이 되는지 비교하기는 어렵다. 현재 병력에 적용되는 대상 수와 역할을 목록에서 먼저 보여 주는 편이 낫다.
3. **승리 후 다음 전투까지의 단계:** 1구역 승리 화면의 주 버튼은 ‘귀환·연구소로’다. 직접 확인한 경로는 결과→연구소→연구소 닫기→홈의 스테이지 선택→다음 스테이지 화살표→출발이었다. 첫 클리어 당시 연구 크레딧을 소모하는 항목은 아직 열리지 않았고, 다음 지역으로 바로 가는 버튼도 없었다. ‘다음 스테이지’를 승리 화면의 주 행동으로 두고 연구소는 선택적으로 열도록 권한다.
4. **후반 전투 길이:** 콘텐츠 정의상 3·4·5구역 최대 시간이 8:30/11:30/16:30이다. 직접 후반을 완주한 결과는 아니지만, 2구역 4분 이후 급격히 길어진다. 더 긴 시간만큼 새로운 선택·보스 변화·성장 보상이 있는지 별도 검증이 필요하다.

## 개선 우선순위

1. **2구역에 쉬운 판단 한 번을 만든다.** 난도 1.5·4분은 유지하고, 예고를 보고 감속 또는 조립을 사용하면 시설에 접근한 적을 처리하기 편해지는 상황을 설계한다. 무조건 적 HP를 올려 생존율만 낮추지는 않는다.
2. **25종 성장표 적용 시 재료 정체를 함께 해결한다.** 재료 정체는 돈과 유닛이 있어도 필요한 종류가 없어 다음 단계로 못 가는 상태다. 6종의 동일 3기 조합, 첫 재료 공급, 만칸에서의 회복, 상위 직접 뽑기를 묶어 비교한다. S의 기본 재료 81기분은 한 판 초기화 구조에서 실제로 모을 수 있는지도 따로 확인한다.
3. **승리 직후 다음 구역으로 바로 이어 준다.** 저장·엔진 차감·해금 조건을 보존하면서 새 구역 진입까지의 불필요한 화면 이동을 줄인다.
4. **유닛과 공격이 읽히는 크기로 전투 화면을 정리한다.** 속성별 외형 차이, 단계별 공격 변화, 적 겹침을 우선 확인하고 신규 아트를 연결한다.

## 검증 한계

- 대장의 브라우저 조작에도 도구 호출·화면 판독 시간이 들어간다. 사람의 반응 속도나 튜토리얼 완료 시간의 측정으로 쓰지 않는다.
- 실제 사람 참가자 0명, 실물 모바일 0대. 고객 만족도·유지율·매출을 예측하지 않았다.
- 음향을 직접 청취하거나 촉각 진동을 시험하지 않았으며 음질·진동 타격감은 평가하지 않았다.
- Unity/iPhone/Android 실기기 실행, 네트워크 지연 환경, 발열·배터리·장시간 성능을 이번에 시험하지 않았다.
- 최신 그림·보스·25종 성장표는 실행 데이터에 아직 반영되지 않았다. 이번 시험 통과를 새 설계의 구현 완료로 해석하지 않는다.
