## 달라진 플레이

로봇 조립과 속성은 이미 있었지만 보통 적은 같은 행동을 반복했다. 이제 첫 두 웨이브의 정찰병을 익힌 뒤 질주·군집·공성 부대가 순서대로 들어온다. 다음 무리의 종류·실제 생성 수·진입로 수·준비 시간을 서버가 예고한다. 냉동과 긴 사거리, 범위·연쇄 공격, 가까운 집중 화력의 용도를 구분하도록 구성했다. 속성 면역은 없다.

전장 오른쪽 아래에는 두 전술이 있다. **과부하**는 본진 로봇 피해를 6초간 50% 높인다. **EMP**는 현재 적의 이동과 시설 공격을 3초, 보스는 1초 멈춘다. 고철을 쓰지 않으며 40초 재사용 시간을 공유한다. 과부하는 본진 로봇이 있을 때, EMP는 적이 있을 때 활성화된다. PC에서는 Q/E로도 사용하며 입력창·모달 뒤에서 오작동하지 않는다. 훈련에는 새로운 전술을 끼워 넣지 않는다.

새 적은 직접 그린 SVG 실루엣으로 구별한다. 실제 적중 기록을 받아 짧은 자세 유지·방향 반동·바닥 잔흔을 그리고, 기절·감속·과부하를 각각 표시한다. 화면 연출 때문에 서버의 전투 시간이 멈추지는 않는다. 속성별 발사·명중·시설 피해·보스 진입 소리는 외부 음원을 쓰지 않고 WebAudio로 합성한다. 음성 수 제한, 좌우 위치감, 경고 우선 처리, 음소거·탭 숨김·원정 전환 시 예약음 취소를 적용했다.

다섯 구역에는 지구 귀환 준비를 잇는 고유 브리핑·관제 통신·결과 대사가 있다. 통신은 조작을 막지 않고 관제 기록에 남는다. 보스가 나타나면 체력·제한 시간 표시가 우선하며, 관제 기록은 설정에서도 열 수 있다. 결과에는 본진의 실제 피해·처치·최대 적 수·최대 단일 적중·시설 받은 피해·도달 웨이브와 전술 사용 횟수, 패배 원인별 다음 시도 힌트를 보여준다. 공동 스토리 피해와 과잉 피해를 본진 통계에 포함하지 않는다. 동료가 계속 싸우거나 재접속해도 개인 종료 시점의 기록은 유지한다.

## 반복 조정과 팀 검토

- 기획 검토: 적 역할의 차이와 사전 정보가 기존 조립 판단으로 이어져야 한다. 복잡한 저항표 대신 체력·속도·공성 피해 차이로 합의했다.
- 개발 검토: 서버 결과와 클라이언트 효과를 연결하고, 전술 재전송·협동 구역 격리·훈련 행동 제한을 검사했다.
- 자동 플레이 관점: 새 버튼이 승리의 필수 반복 입력이 되지 않도록 무지원 정책과 사용 정책을 함께 비교했다. 이는 실제 프로게이머나 소비자의 의견이 아니다.
- 균형 조정: 3/4/5구역 보스 체력을 각각 30,000→25,500 / 70,000→59,500 / 135,000→114,750으로 낮췄다. 무지원 dispatch 정책의 20시드 클리어는 12/9/6→14/15/13회. 실패도 남으며 다른 편성이나 사람에게 같은 비율을 보장하지 않는다.
- 최종 비교는 다섯 구역 × 20시드 × 9정책, 총 **900회**. 기준선과 수치·한계는 [전투 균형 보고서](2026-09-26-combat-balance.md)에 있다.

발견 후 수정한 문제: 개인 패배 후 결과 웨이브/통신 시각 변경, 계단식 채굴 진행과 통신 시각 불일치, 보스 명칭 불일치, 처음부터 음소거한 사용자의 효과음 재활성화 실패, 통신 패널의 과도한 높이, 예고 패널과 협동 버튼 겹침 및 로봇 터치 차단. 콘텐츠 검증에는 적 역할 누락·초반 일반 적 보장·빈 웨이브 방지·전술 지속/재사용 시간 관계도 추가했다.

최종 검토에서 채굴장 마지막 슬롯과 지원 상태 문구가 겹쳐 선택을 막는 문제를 추가로 발견했다. 실제 전술 버튼만 입력을 받고 문구/빈 공간은 Canvas로 전달하도록 수정했으며, 신규 브라우저 검사에 직접 클릭 회귀를 추가했다. 네 규격·다섯 맵·네 희귀도 중심 좌표의 DOM 가림 검사에서 수정 후 차단 0개를 확인했다. 기존 네트워크 자동 조작기는 0.7초 뽑기 대기시간을 반영하지 않아 즉시 실패했으므로, 게임 규칙은 유지하고 자동 조작기가 서버의 남은 대기시간을 읽도록 고쳤다.

로컬 기본 서버 `http://127.0.0.1:7351`도 실행했고 agent-browser로 홈 렌더링·스테이지 이동·오류 없음 확인을 마쳤다. 서버는 별도로 종료하기 전까지 현재 머신에서 실행된다.

화면: `artifacts/reignition/{360,390,667,1440}-{home,briefing,battle,intel,overdrive,emp,boss,report}.png`. 해당 폴더는 생성 산출물로 Git에서 제외되며 검사 명령으로 재생성할 수 있다. 최종 창 상태에 따라 보고서의 아래쪽을 스크롤한 캡처도 있다.

## 출시 판단의 남은 조건

이번 결과물은 브라우저에서 플레이·검증할 수 있는 패치다. 실제 사용자 재미/이탈률, 실물 iPhone 발열·프레임·터치·오디오 전환, WAN 협동 지연, 장기 저장/계정 동기화는 아직 검증되지 않았다. Unity 클라이언트는 기존 프로토타입이며 이번 전술·예고·UI/연출을 아직 이식하지 않았다. 앱스토어 결제·배포도 연결되지 않았다. 따라서 **상용 출시 인증이나 소비자 만족 검증 완료로 취급하지 않는다.** 다음 품질 판단에는 실제 기기와 사람의 전체 원정 플레이 기록이 필요하다.
