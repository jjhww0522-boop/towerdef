# 강화 통일·초반 전투·캐주얼 그래픽·2구역 가독성

사용자 지시를 이어서 적용하는 구현 계획이다. 일상적인 개발·검증은 추가 승인 없이 진행한다. 콘텐츠 기준은 `0.13.1-casual-pressure`다.

1. 강화 9분류를 현재 6속성으로 통일한다. 웹·C#·서버가 같은 의미로 동작하는지 실제 피해, 비용, 재전송, 새로 뽑은 유닛까지 검사한다. 공통 S는 여섯 강화 중 최대 단계 하나만 받는다.
2. 1구역의 난이도 1, 최대 3분, 시작 60고철을 유지하면서 일반 적의 체력·등장 간격을 조정한다. 등장과 동시에 죽는 비율, 생존 시간, 화면의 적 수, 무입력·조립·강화·판매 실수 정책을 비교한다. 승률만으로 재미를 판정하지 않는다.
3. 25종 가전 유닛과 적을 둥근 형태·큰 표정·정돈된 외곽선의 귀여운 만화풍으로 바꾼다. 기존 직접 제작 벡터를 개선하고 실제 게임 및 Unity용 PNG에 반영한다. 대기·준비·발사·회복 동작과 48/64픽셀 식별성을 확인한다.
4. 2구역의 12칸·통로를 화면 방향에 맞게 투영해 유닛과 적을 구별하기 쉽게 만든다. 전장에 배정하는 면적·터치 영역·표시 크기·HUD 간섭을 확인한다. 전투 좌표·사거리·실제 경로는 유지한다.
5. 통합 빌드, 자동 회귀, 모바일 크기의 실제 브라우저 입력, 그림 디코딩·잘림 검사와 독립 밸런스 비교를 수행한다. 소유한 미리보기 서버만 갱신하고 이전 저장 데이터는 보존한다.

담당: 대장(서버 강화·콘텐츠·통합), 기획·밸런스팀(독립 계측), 클라이언트·UI/UX팀(강화 화면·2구역 투영), QA 후 아트·사운드팀으로 재배정한 작업자(새 강화 검사·캐릭터/출력).

출시 수준이나 사람의 만족도는 자동 검사로 보장할 수 없다. 실제 휴대폰·Unity 실행·사람 플레이는 수행 사실이 있을 때만 기록한다. 외부 캐릭터·게임 자산은 추출하지 않는다.

실행 완료: 강화·1구역 수치·25+5종 아트·2구역 투영/선택을 적용하고 통합280검사, C#19검사, 최종 화면 관련53검사, 2구역84터치, 530PNG 출력 검사를 통과했다. 7354 미리보기와 저장 데이터를 확인했다. [최종 기록과 한계](../../playtests/2026-09-27-casual-pressure.md)에 세부 근거를 남겼다.
