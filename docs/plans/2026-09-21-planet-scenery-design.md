# 행성 채굴장과 우주 배경

사용자는 공장처럼 보이는 현재 전장을, 희미한 다른 행성과 우주 공간이 보이고 스테이지별 행성 특성이 드러나는 배경으로 발전시키기를 요청했다. 기존 자율 제작 범위에서 배경 표현을 변경한다.

시각 방향: 대기가 옅은 행성의 야외 채굴지. 먼 성운·행성, 낮은 지평선, 가까운 광물 지형을 겹쳐 깊이를 만든다. 로봇과 적은 가장 선명하게, 하늘과 지형은 낮은 대비로 표현한다.

구성: 고물 궤도는 회갈색 분화구와 먼 청회색 행성, 코발트 사구는 푸른 모래 능선과 고리 행성, 성운 심층부는 보랏빛 광맥과 옅은 성운/위성이다. 기존 적 경로·배치 위치·채굴기·스토리 발판을 유지하고 넓은 철판 격자를 행성 지형으로 대체한다. 하늘만 바꾸는 안보다 행성의 개성이 분명하고, 전장을 새로 배치하는 안보다 조작 연속성을 유지한다.

상호작용: 배경은 시선을 끄는 독립 애니메이션 없이 정적으로 캐시한다. 기존 채굴기·발사·조립 움직임이 전경의 주인공이다. 유닛 선택 상자는 전장 위에 뜨며 화면 크기를 바꾸지 않는다. 게임 규칙과 모바일 HUD는 변경하지 않는다.

1. 기존 캐시 안에서 우주 하늘·행성·지형 렌더링 → 장면 전환 시 갱신, 매 프레임 재생성 방지 확인.
2. 세 행성을 실제 브라우저에서 세로·가로로 확인 → 색뿐 아니라 지형/천체 차이, 경로·유닛 대비 확인.
3. 기존 렌더러·전투·모바일 검사 → 선택, 좌표, 조작, 브라우저 오류 회귀 확인.

표현은 기존 Canvas 도형/그라데이션으로 제작하여 추가 다운로드나 외부 이미지 의존성을 만들지 않는다. 물리 iPhone 성능과 인간 플레이 가독성 평가는 별도다.

완료: 세 행성×390×844/844×390/1440×900의 9장면에서 서로 다른 배경, 캐시 재사용, 좌표 보존을 확인했다. 세로/가로 캡처를 직접 검토했다. 초기 배경 전투 연출 8검사, 최종 배경+판매에서 렌더러/원정 29검사·모바일 330검사·브라우저 품질 26검사 통과. 가로 장면의 천체는 HUD를 피하도록 오른쪽 여백에 배치했다.
