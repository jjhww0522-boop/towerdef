# 엔진과 챕터 1 구현 계획

승인: 엔진 최대 5개, 새 원정 참가당 1개 소모, 30분마다 1개 회복, 유료 즉시 충전. 같은 고물 행성에 다섯 스테이지.

## 엔진
- 최초 5개. 일반/배속 연습 모두 새 참가에 1개 사용. 실패/중도 이탈 환급 없음.
- 같은 원정 재접속/재시도 무료. 거절된 입장은 차감 없음.
- 서버 시계로 오프라인 회복. 가득 찬 동안 회복 시간을 비축하지 않음.
- 기존 저장 기록은 유지하고 엔진 필드가 없는 계정만 5개로 시작.
- 유료 상품은 엔진 즉시 완충. 서버에서 검증한 거래만 적용, 거래 재사용 차단.
- 스토어 정보가 없어 실제 결제는 비활성. 연결 전임을 화면에 표시. 검증 연결점과 원자적 지급만 구현하며 실제 결제 완료로 보고하지 않음.
- 서버 재시작 시 기존 인메모리 원정은 사라짐. 살아 있는 동일 원정 재접속만 무료이며 원정 영구 복구는 별도 작업.

## 챕터 1
- 기존 1~3의 식별자/시간/목표/연구 기록 유지. 4~5 추가.
- 착륙 지대, 채굴장, 엔진 기지, 좁은 협곡, 탈출항. 공통 행성 배경과 서로 다른 경로/배치 위치/수.
- 서버와 Canvas는 같은 geometry 사용. 랜덤 소환/선택 자리 조립 유지. 확률과 조합식 변경 없음.
- 직전 스테이지 클리어 시 다음 해금. 새 4/5는 10분/15분 방어 후 보스. 난이도는 기존 수치 기반 초기값.

## 검증
1. 저장/회복: 30분 경계, 연속 차감, 오프라인, 최대치, 기존 데이터, 저장 실패.
2. API: 입장 실패, 재접속, 중복 요청, 위조 결제, 검증 거래 재전송/타 계정 재사용.
3. 맵: 슬롯/경로 차이, 서버/화면 좌표, 사거리, 조립 위치, 시설 정지 공격.
4. 모바일 홈→선택→입장, 엔진 부족/회복, 5개 맵 캡처. 빌드/회귀 검사 후 푸시.
