# 성장형 챕터 1과 기동 훈련

날짜: 2026-09-23 · 콘텐츠: `0.10.0-growing-expedition`

사용자 승인 범위는 처음에는 작은 전장과 적은 조합으로 시작하고, 스테이지를 깨면서 배치 수·조합 선택지·방어 시간이 늘어나는 구조다. 뽑기에 0.7초 간격을 두고, 무료 훈련에서 뽑기·선택·판매·조립·보스를 직접 경험하게 한다. 아래는 현재 서버 규칙과 승인된 화면 동선을 기록한다. 출시 밸런스나 사람 대상 조사 결과가 아니다.

## 챕터 1

| 단계 | 경로 / 전장 좌표 | 배치 수 | 방어 시간 | 보스 제한 | 최대 전투 시간 |
| --- | --- | ---: | ---: | ---: | ---: |
| 1-1 착륙 지대 | 순환 / 420×220 | 10 | 3분 | 1분 | 4:00 |
| 1-2 채굴장 | 위→아래 / 600×1440 | 12 | 5분 | 없음 | 5:00 |
| 1-3 엔진 기지 | 왼쪽→오른쪽 / 1640×800 | 14 | 7분 | 1분 30초 | 8:30 |
| 1-4 좁은 협곡 | 양쪽→중앙 / 1920×880 | 16 | 10분 | 1분 30초 | 11:30 |
| 1-5 탈출항 | 십자→중앙 / 1440×1440 | 20 | 15분 | 1분 30초 | 16:30 |

방어 시간은 보스 출현 전 구간이다. 2번은 채굴기를 끝까지 보호하면 보스 없이 완료한다. 나머지는 보스를 처치해야 클리어하며 실제 종료 시각은 처치 속도에 따라 다르다. 1번은 적 35기 이상 상태가 5초 유지되면 패배한다. 2~5번은 시설 체력이 0이 되면 패배하고, 도착한 적은 멈춰 계속 공격한다. 시설 파괴와 완료가 같은 틱이면 파괴가 우선한다.

시설 체력은 3,500/5,000/7,000/9,000, 일반 적의 초당 시설 피해는 4/5/5/6이다. 보스는 6배 피해를 주며 냉동은 도착만 늦춘다. 적 체력 성장·생성 간격·웨이브 수입·스토리도 단계에 맞춘 시험값으로 조정했다. 여러 입구는 전체 적 생성량을 나눠 사용한다. 현재는 1인과 4인이 같은 스테이지 시간표를 사용하며, 별도 20/30분 협동 모드는 후속 범위다.

기본 9종·전체 29종과 조합 재료 20개는 유지한다. 기본/개조/특급 뽑기 확률 93%/6.8%/0.2%와 유닛 능력치는 이번 작업에서 바꾸지 않는다. 전장 축소가 공격 능력을 바꾸지 않도록 범위 추가 반경 115.92, 연쇄 반경 193.2 전장 단위를 보존했다. 순환 맵은 경로 거리, 열린 맵은 실제 좌표 거리로 판정한다.

## 조합 해금

조합표에서 숨기기만 하는 제한이 아니다. 아직 얻지 않은 조합은 재료가 있어도 서버가 `RECIPE_LOCKED`로 거절한다. 직접 뽑기 확률은 기존 방식이며 조합 해금 여부가 뽑기 확률을 바꾸지는 않는다.

| 조건 | 새로 사용 가능한 조합 | 개수 / 비용 |
| --- | --- | --- |
| 시작 | 볼트가드, 캔스캐너, 렌즈아이, 궤도램, 충전대장 | 5개 / 무료 |
| 1-1 클리어 | 수거대장, 패널키퍼, 코일메이커, 스파크포 | 4개 / 자동 |
| 1-2 클리어 | 볼트타이탄, 고철박사, 궤도브레이커 | 3개 / 자동 |
| 1-3 클리어 | 오비탈옵저버, 스파크펀처, 플라즈마캐스터 | 3개 / 자동 |
| 1-4 클리어 | 고철거신 | 1개 / 자동 |
| 1-3 클리어 후 연구 | 아크캐리어 | 60 연구 크레딧 |
| 1-4 클리어 후 연구 | 오비탈마더 | 100 연구 크레딧 |
| 1-5 클리어 후 연구 | 스타라이트코어, 성운방주 | 각각 160 / 240 연구 크레딧 |

시작 5개 + 자동 11개 + 연구 4개 = 조합식 20개다. 자동 해금의 데이터 계약은 `unlockType:'clear'`, `unlockBattlefield>0`, `researchCost:0`이다. 지정된 단계의 정상 클리어를 정산할 때 추가하고, 기존 프로필의 클리어 기록에서도 복원한다. 연구 API는 자동 조합의 구매를 거절한다. 패배·이탈·연습·기동 훈련은 자동 조합이나 다음 스테이지를 열지 않는다. 진행 중인 원정의 사용 가능 조합은 입장 당시 서버 프로필을 기준으로 한다.

## 뽑기 간격

첫 뽑기는 즉시 가능하다. 성공한 뽑기 이후 개인별로 7틱, 기본 속도에서 0.7초를 기다린다. 실패한 요청은 고철·유닛 종류 난수·배치 난수·대기시간을 소비하지 않는다. 조립·판매·강화는 이 대기시간과 별개로 실행할 수 있다.

서버 내부 `nextSummonTick`, 공개 상태 `summonCooldownRemainingTicks`, 거절 코드 `SUMMON_COOLDOWN`을 사용한다. 같은 요청 번호의 재전송은 원래 결과를 유지하고 대기시간을 연장하지 않는다. 재접속도 대기시간을 초기화하지 않는다. 3·6배속 연습은 시뮬레이션 틱에 맞춰 뽑기 간격도 가속한다. 화면은 공개 남은 틱으로 버튼 상태와 채움 표시를 그린다.

## 기동 훈련

홈의 **기동 훈련**에서 진입하는 1인 전용 모드다. 일반 스테이지와 별도 `battlefieldId:0`, 3칸, 속도 1, 판내 고철 100으로 시작한다. 엔진이 0개여도 입장할 수 있고 엔진을 사용하지 않는다. 일반·배속 연습 원정은 기존대로 새 참가마다 엔진 1개가 필요하다.

1. 안내를 확인한 뒤 첫 로봇을 뽑는다.
2. 첫 로봇을 선택해 사거리와 상세를 확인한다.
3. 두 기를 더 뽑아 세 칸을 채운다.
4. 지정된 로봇을 판매해 빈칸과 돌려받는 고철을 확인한다.
5. 다시 뽑아 조립 재료를 만든다.
6. 처음 선택한 로봇을 기준으로 조립해 같은 자리에 결과가 남는 것을 확인한다.
7. 준비를 누르면 8초 후 보스가 등장한다. 보스를 60초 안에 처치하면 훈련이 끝난다.

훈련의 뽑기는 렌즈봇→패널봇→점화봇→코일봇 순서이며 첫 빈칸에 배치한다. 점화봇을 판매한 뒤 렌즈봇+코일봇으로 렌즈아이를 만드는 고정 학습 경로다. 일반 원정에서는 종류와 빈칸 위치가 무작위다. 고정 훈련 배치는 일반 뽑기의 확률 보장을 의미하지 않는다. 강화·파견과 공동 스토리는 이번 훈련에 포함하지 않는다.

서버가 단계에 맞는 행동만 허용한다. 다른 계정은 훈련 방에 들어갈 수 없고 같은 계정은 기존 상태로 재접속한다. 일반 방 초대에 `tutorial:true`를 붙여도 방의 실제 모드를 따르므로 엔진 차감을 피할 수 없다.

완료 시 `profile.tutorialCompleted`만 true로 저장한다. 처음에는 false이며 구 프로필에서 누락돼도 false로 읽는다. `completeTutorial(profileId)`는 첫 완료에 `{applied:true,profile}`, 반복에는 `{applied:false,profile}`을 반환한다. 연구 크레딧·조합·다음 스테이지·클리어 전적·엔진 보상을 지급하지 않는다. 중도 포기는 완료로 기록하지 않는다. 훈련 중 고철과 로봇은 해당 훈련 안에서만 사용한다.

## 공식 자료와 적용 판단

- Clash Royale의 공식 지원 문서는 Training Camp와 Practice Mode가 봇 상대 연습이며 재화를 얻거나 잃지 않는다고 설명한다. 이 텍스트에서 **학습을 재화 손익과 분리하는 방식**을 참고했다. 우리 게임의 엔진 무료 3칸 훈련과 완료 기록만 남기는 처리는 자체 설계다. [공식 Training Camp & Practice Mode](https://support.clashroyale.com/hc/en-us/articles/49484905512219-Training-Camp-Practice-Mode)
- Brawl Stars의 2025-07-01 개발 글은 초보 튜토리얼과 보상·시각 표현을 개선한 Trophy Road를 함께 개선 목표로 제시한다. 이를 **첫 행동 학습을 이후 성장 동선에 연결한다**는 방향으로 해석해, 훈련→첫 스테이지→조합 자동 해금에 적용했다. 해당 글이 우리 구성의 성공이나 학습 효과를 입증하는 것은 아니다. [공식 About the Update & Records Changes](https://supercell.com/en/games/brawlstars/blog/game-updates/about-the-update-records-changes/)

이번 참고는 두 공식 페이지의 텍스트를 읽은 것이다. 경쟁작 튜토리얼을 직접 플레이하거나 이미지·동작 시간을 관찰한 조사로 보고하지 않는다. 가상 소비자 의견 역시 실제 사용자 설문을 대신하지 않는다.

### 고정 자동 전략 관찰

[최종 자동 전략 기록](../../artifacts/growing-expedition-smoke.json)은 로컬 산출물(`artifacts/`는 Git 제외)이다. 집계는 아래 표에도 보존한다. 실행 구성은 `scriptedMatch(seats, seed, 'dispatch', false, {battlefieldId, practice:false})`의 4인/1인, 5단계, seed 1/2/3과 4인 무입력 5매치를 합친 35매치다. 각 단계는 이전 스테이지의 자동 조합만 얻은 상태이고 연구 4종은 사용하지 않았다. 봇은 기존 1초 판단 주기를 사용하며 뽑기 가능 틱을 확인한다.

| --- | ---: | ---: |
| 1 | 12/12 | 3/3 |
| 2 | 12/12 | 3/3 |
| 3 | 8/12 | 1/3 |
| 4 | 7/12 | 2/3 |
| 5 | 6/12 | 1/3 |

1번의 실제 종료는 200.8~206.2초였다. 무입력은 1번에서 57.4초에 적체 패배, 2~5번에서 각각 89.6/96.5/91.3/86초에 시설 파괴로 패배했고 보상은 모두 0이었다. 입력 전략의 후반 패배 사유는 보스 제한시간 초과였다. 이것은 고정 정책·3시드의 성립 사례이며 사람의 승률, 난도 순서의 통계적 증명, 네트워크/모바일 성능 검증이 아니다. 특히 작은 화면에서 배치·사거리·조합 전환을 읽고 조작할 수 있는지는 실제 플레이로 확인해야 한다.
