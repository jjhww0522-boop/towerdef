# 위치 운과 속성별 전투 구현

## 적용 범위

`0.6.0-position-combat`은 기존 29종/20조합을 유지한 전투 실험이다. 생활용품 로봇의 최종 이름·조합표·아트, 싱글 5/10/15분과 협동 20/30분 시간표, 희귀 조커 유닛은 이 구현에 포함하지 않았다.

- 자기 전장의 빈 슬롯 중 균등 추첨한다. 파견 복귀 슬롯은 예약되며, 배치 난수는 유닛 종류의 난수와 분리한다. 동일 요청 재시도는 슬롯/유닛/비용을 다시 추첨하거나 소비하지 않는다.
- 조립 요청의 `unitIds[0]`이 사용자가 선택한 실제 재료 개체다. 서버는 기존 소유권·중복·해금·재료 검증 후 그 개체의 슬롯을 결과에 사용한다. 도감은 위치 선택 후 상세의 조립 버튼을 눌러 실행한다.
- 공통 전장 좌표로 주 대상의 사거리를 판정한다. 사거리 안의 가장 오래 남은 적을 선택하며, 없으면 발사하지 않는다. 범위/연쇄의 추가 대상은 기존 적 간 경로 거리 기준을 유지한다.
- 화염 4종은 공격력 약 1.8배와 사거리 160, 바람/냉동은 250, 전격은 300, 레이저는 520을 시험한다. 바람은 주 대상 80%·인접 최대 2기 각각 45%, 레이저는 단일 대상이다.
- 냉동은 2초간 일반 적 35%·보스 15% 감속이다. 여러 냉동 로봇은 감속 강도를 중첩하지 않고 지속시간을 갱신한다. 파견 중 공격은 홈 라인에 피해나 감속을 주지 않는다.
- 선택 시 실제 사거리 영역과 속성을 표시한다. 설명 상자는 선택 로봇의 반대쪽에 표시하고 전장 크기를 바꾸지 않는다. 세로 화면은 동일한 10×3 슬롯 관계를 회전해 3×10으로 표시한다.

## 사거리 도입에 따른 실험 수치 보정

초기 자동 전략은 공격 가능 시간을 고려하지 않아 성장/판매/배치가 불리했다. 비교용 전략은 합칠 재료 중 결과 유닛이 경로를 더 오래 공격할 수 있는 자리를 선택하고, 판매 후보 평가에도 경로 도달 비율을 사용하도록 수정했다. 이는 공개 규칙으로 가능한 행동이며 게임 내부에 자동 배치 보정이나 결과 보장을 추가한 것이 아니다.

화염 재료 상향으로 고철거신 조립 후 주 대상 피해가 재료 합계보다 떨어져, 공격력 550→600으로 보정했다. 공격 중 주 대상 DPS는 480이고 재료 합은 456이다. 사거리 밖 대기와 광역 피해는 이 값에 포함하지 않는다.

장기 행성의 기존 보스 체력은 사거리 제한이 없던 전투에 맞춰져 있었다. 실제 공격 기회 감소를 반영한 시험값으로 두 번째 행성 550,000→450,000, 세 번째 850,000→500,000으로 조정했다. 파견·조합을 수행하는 자동 전략으로 별도 시드 101~110, 행성당 4인×10판을 확인했으며 각각 27/40, 24/40 개인 라인이 클리어했다. 이는 사람의 승률·재미·정식 난이도 검증이 아니다.

## 검증

- Node/서버 전체 105검사 통과. 6,000회 위치 분포, 종류 추첨과의 독립성, 파견 칸/한도/재시도, 높은 슬롯 번호를 선택한 조립, 사거리 밖 대기, 레이저 단일 공격, 감속 지속/종료/중첩/보스 효과를 포함한다.
- 모바일 7조건·330검사 통과. 정보 상자 30% 제한, 실제 캔버스 터치, 선택 변경, 판매, 카메라/로봇 좌표 보존을 확인했다.
- 브라우저 품질 26검사 통과. 실제 뽑기 재료를 조립할 때 선택한 개체의 슬롯을 결과가 이어받는지 확인했다.
- 위치 전용 브라우저 3조건 통과. 통제된 서버 재료로 슬롯 26을 선택해 슬롯 2보다 우선 보존하는지, 도감 위치 선택의 비소모성, 감속 표시, 회전 후 슬롯 보존을 확인했다.
- 전투 연출 8검사 통과. 실제 공격 신호, 조립 효과, 웨이브/보스 경고, 음소거와 움직임 줄이기를 확인했다. 데스크톱 헤드리스 부하 장면의 프레임 간격 중앙값은 50ms로, 60fps나 모바일 실기 성능을 보장하지 않는다.
- 보고서와 캡처는 `artifacts/position-combat-browser-report.json`, `position-combat-*.png`, `position-balance-report.json`, `mobile-layout-report.json`, `browser-quality-report.json`에 생성한다. 이 폴더는 Git에서 제외되며 검사 명령으로 재생성할 수 있다.
