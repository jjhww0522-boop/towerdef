# 로봇 판매와 고철 회수

사용자는 유닛 판매/회수 기능을 요청했다. 기존 서버의 해체(`salvage`)는 누적 뽑기 비용의 35%를 내림하여 고철로 돌려주지만 화면의 조립 목록 끝에 숨어 있다. 이를 선택 상자에서 바로 찾을 수 있는 ‘판매’로 개선한다.

유닛 선택 → 판매 → 대상 이름과 회수 고철 확인 → 판매 확정. 확인은 기존 상자 안에서 조립 내용을 대체하며 전장을 줄이거나 새 모달을 쌓지 않는다. 취소·다른 유닛 선택·상자 닫기는 판매하지 않는다. 대상이 바뀌면 확인도 새로 해야 한다. 실제 판매는 정확한 한 개체를 서버가 검증하고 승인했을 때 반영한다.

기존 환급 비율·파견 중 판매 불가·중복 요청 처리·조립 재료 누적 비용 계산을 유지한다. 별도의 대기석/배치 회수/스토리 파견 취소는 이번 판매 기능과 구분한다.

검증: 기존 서버 판매 검사, 세로·가로의 44px 판매/확정 버튼과 30% 상한, 취소 시 무변경, 선택 교체 시 재확인, 실제 판매의 개체/환급/닫기 흐름.

완료: 7개 모바일 조건에 판매 확인·취소·다른 유닛 선택·실제 확정을 추가하여 330검사 통과. 렌더러/원정 29검사와 브라우저 품질 26검사도 통과했다. 서버 검사는 정확한 환급·중복 요청·파견/타인 유닛 거부를 확인한다. 실제 브라우저에서는 판매한 한 개체만 제거되고 표시 환급이 지급되며 전장 크기가 유지됨을 확인했다.
