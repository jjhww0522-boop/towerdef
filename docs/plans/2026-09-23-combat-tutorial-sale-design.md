# 전투에서 배우는 조립과 바로 판매

2026-09-23. 사용자 요청: 첫 로봇으로 적을 막다가 화력이 부족해 조립이 필요함을 체험하고, 판매를 로봇 선택 화면에서 바로 시작한다.

1. 렌즈봇·패널봇 2기를 고정 뽑기하고 8초 방어전을 경험한다. 훈련 적 3기가 차례로 나오며 일반 사거리·공격 판정으로 전투한다. 적이 남은 상태에서 조립 학습으로 전환한다.
2. 설명·재료 확보·판매·조립 중에는 훈련 전투만 일시 정지한다. 적 체력/위치와 공격 대기/감속 남은 시간은 보존하며 뽑기 쿨타임은 진행한다. 조립 뒤 같은 적을 실제 공격으로 마무리해야 보스 준비가 열린다.
3. 기존 3칸·고정 4회 뽑기·선택 자리 조립·8초 보스 예고·무료/보상 없음 규칙은 유지한다. 일반 원정의 밸런스는 바꾸지 않는다.
4. 로봇 선택 팝업에 판매를 직접 표시한다. 판매를 누르면 로봇명·판매 시 소멸·반환 고철을 표시하는 확인 창이 열린다. 기본 초점은 취소이며 취소/Escape는 행동 요청을 보내지 않는다. 실제 제거·고철 지급은 확인 후 서버 응답으로 결정한다.

검증: 실제 초반 공격과 적 잔존, 학습 중 정지/재접속, 조립 후 더 높은 피해와 자연 처치, 최종 보스/완료 기록 분리를 core/API로 확인한다. 브라우저에서는 360×640·390×844·667×375의 로봇 직접 터치, 즉시 판매·취소·확정, 전장 크기 유지와 가림 여부를 확인한다. 일반 원정의 판매도 같은 확인 흐름을 검증한다.

## 검증 결과

- 전체 빌드·콘텐츠 검증과 Node 테스트 197개 통과. 튜토리얼 core/API 20개 포함.
- 튜토리얼/일반 판매 브라우저 검사 12개 통과(360×640·390×844·667×375). 취소·Escape에는 요청과 재화 변화가 없고, 확인 때만 정확히 한 번 판매된다. 초반 실제 교전·조립 후 같은 적 처치·보스·재접속·무료 훈련을 확인했다.
- 기존 위치/조립 팝업 검사 3규격 통과. 기준 자리 조립·사거리·감속·회전 후 선택 로봇 노출을 확인했다.
- JavaScript 오류 없음. 실제 휴대폰 성능과 초보자 학습 효과는 별도 플레이테스트가 필요하다.
