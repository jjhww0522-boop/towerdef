# 유닛 선택 정보 상자

사용자가 앞서 제안한 비차단 정보 상자 설계를 승인했다. 현재의 전장 축소형 유닛 상세창을, 전장 위에 겹쳐지는 작은 상자로 바꾼다.

시각 방향: 기존 철제 채굴장과 HUD를 유지하며, 충분히 불투명한 작은 패널 하나로 선택 정보와 조립 행동을 묶는다. 전장 크기와 유닛 배치는 선택 전후 동일해야 한다.

정보 구성: 이름·등급·공격 역할과 조립 경로의 요약을 먼저 표시한다. 세부 수치·사용처는 기존 상세 펼치기로 확인한다. 상자는 전장 하단의 일정한 위치에 두고 협동 띠와 수거/관리 버튼을 가리지 않는다. 최대 높이는 화면의 30%이며 긴 내용만 내부에서 스크롤한다.

상호작용: 화면 전체를 어둡게 하거나 입력을 막지 않는다. 다른 로봇을 누르면 같은 상자의 내용과 선택 테두리만 바뀐다. 빈 전장·닫기·Escape로 닫는다. 파견 대기와 조립은 기존 서버 검증/소모 흐름을 유지한다. 기존 관리 탭의 동작은 이번 수정 범위에 포함하지 않는다.

1. 유닛 창의 레이아웃 점유와 모달 입력 차단 제거 → 열기/교체/닫기 전후 캔버스 크기·월드 좌표가 같은지 확인.
2. 정보 상자 크기와 닫기/선택 처리 → 세로·가로 화면에서 30% 상한, 44px 터치, 다른 로봇/빈 전장/수거 버튼 조작 확인.
3. 조립·파견·상세 확인 회귀 → 기존 모바일/브라우저 검사와 실제 브라우저 캡처, 관련 렌더러 검사 실행.

구현 완료: `dialog.show()`와 전장 내부 절대 위치를 사용하며, 유닛 선택을 하단 공간 계산에서 제외했다. 빈 캔버스 터치는 선택 해제를 전달한다. 관리 창과 서버 전투 규칙은 유지했다.

검증: 렌더러 18/18, 모바일 7조건·288검사, 브라우저 품질 26검사, 원정/연구 19검사 통과. 선택 전후 캔버스 크기·카메라·로봇 좌표 동일, 다른 로봇 교체, 빈 전장/Escape 닫기, 비모달 입력, 30% 높이와 44px 터치를 확인했다. 390×844와 667×375 실제 브라우저 캡처도 확인했다. iPhone 실기 검증은 별도다.
