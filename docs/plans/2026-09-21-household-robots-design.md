# 생활용품 자체가 로봇인 원정대

## 사용자와 확정한 방향

사용자는 전문적인 기계 이름보다 속성을 쉽게 유추할 수 있는 생활용품을 원한다. 기본 등급은 라이터·물총·헤어드라이어·제빙기·레이저포인터 같은 익숙한 물건, 상위 등급은 화염방사기·물대포·강풍기처럼 기능과 규모가 커진 장비로 발전한다. 최상위 이름에는 캐논·탱크·화염 등 강력한 인상을 주는 단어를 사용할 수 있다.

외형은 **생활용품 자체에 눈·다리·바퀴 같은 기계적 특징이 붙은 로봇**이다. 사람 형태가 생활용품을 들고 있는 디자인은 사용자가 선택한 방향이 아니다. 귀여운 동료와 거친 우주 생존이라는 기존 분위기를 유지한다.

전투 방향도 추가됐다. 사용자는 **랜덤 위치 소환·선택 재료 위치에서 조립**, 화염의 짧은 사거리와 강한 화력, 바람의 스플래시, 냉동의 감속, 레이저의 긴 사거리와 단일 공격을 지정했다. `0.6.0-position-combat`에서 기존 29종에 시험용 속성과 사거리를 배정해 이 전투 규칙을 구현했다. 생활용품 로봇의 최종 이름·아트·조합식과 밸런스 수치는 여전히 미정이다. 상세는 [위치 전투 구현](2026-09-21-position-combat.md)에 있다.

## 외형 제작 기준

- 몸의 주된 윤곽은 원래 물건을 보존한다. 별도의 머리와 몸통을 먼저 만들고 작은 장비를 덧붙이지 않는다.
- 눈은 용기·표시창·몸체에 붙인다. 다리·바퀴는 이동 방식을 설명할 정도로만 단순하게 추가한다.
- 라이터의 점화 휠/덮개, 물총의 물통/총구, 드라이어의 손잡이/흡기구처럼 알아보게 하는 부품을 크게 유지한다.
- 상위 등급에서도 원래 물건의 대표 부품을 남겨 성장의 연결감을 준다.
- 멀리서도 구분되는 형태가 우선이고, 색은 보조 수단이다. 작은 전투 크기에서 읽히지 않는 배선·볼트 장식은 줄인다.

## 검토용 기본 시안

| 이름 후보 | 주요 실루엣 | 동작 방향 |
| --- | --- | --- |
| 라이터 | 금속 덮개와 점화 휠이 보이는 세로형 몸체 | 짧은 다리, 점화 휠 회전과 불꽃 |
| 물총 | 큰 물통과 총구가 붙은 물총 몸체 | 작은 바퀴, 분사 반동 |
| 드라이어 | 흡기구·원통 노즐·손잡이 | 손잡이 아래 다리, 내부 팬 회전 |
| 제빙기 | 얼음 출구와 투명 보관통 | 낮은 바퀴, 얼음 배출 |
| 레이저포인터 | 길고 가는 원통과 앞쪽 렌즈 | 짧은 다리 또는 받침, 렌즈 점등 |
| 전기모기채 | 망이 있는 타원형 헤드와 긴 손잡이 | 접점 두 다리, 망을 따라 짧은 전기 |

이는 6종의 외형 비교용 후보이며 29종 전체의 최종 이름/조합표는 아니다. 현재 코드의 명칭·조합·아트는 기존 로봇 버전이며, 사거리·속성 전투의 시험 구현은 별도 기록을 따른다.

## 다음 구체화

기본 재료군의 수와 생활용품 구성은 판의 경제·조합 경로를 함께 검증한 뒤 결정한다. 현재 구현의 기본 9종과 제작팀이 제안한 총 42종(9/12/12/6/3)은 최종 로스터로 확정하지 않았다. 서로 다른 기능을 섞는 조합과 상위 기체의 윤곽을 함께 정리하되, 예시인 라이터+드라이어→화염방사기는 기능 조합의 설명이며 현재 확정 조합식이 아니다. 게임에 적용할 때는 표현 변경과 실제 전투 효과 변경을 각각 검증한다.

## 난이도 설계에 관한 사용자 요구

사용자는 맵 특성, 목표 플레이 시간, 시간에 따른 적·보스 성장, 개별 뽑기 확률과 조합에 필요한 재료를 갖출 확률을 함께 고려해 신중하게 난이도를 정할 것을 요구했다. 특히 기본 유닛의 추가·삭제가 기존 조합 전체에 영향을 주므로 기본 재료군을 먼저 확정하지 않는다. 현재 93%/6.8%/0.2%도 구현 중인 실험값이며 검증된 출시 비율이 아니다.

### 확률 영향의 계산 예시

기본 등급이 93%이고 등급 내 균등 추첨이라고 가정한다. 서로 다른 기본 재료 A 3개·B 2개·C 2개를 30회 뽑기 안에 모두 얻을 확률을, 각 재료의 필요 수량까지 상태를 누적하는 정확한 동적 계획법으로 계산했다.

| 기본 종류 수 | 특정 기본 1종의 확률 | 예시 재료 전체 확보 확률 |
| --- | --- | --- |
| 9종 | 약 10.3333% | 약 40.1920% |
| 10종 | 9.3% | 약 30.6632% |
| 12종 | 7.75% | 약 17.5184% |

이는 독립 추첨·고정 30회·재료 소비 없음·보유 제한 없음의 수학 예시다. 직접 뽑은 상위 유닛으로 재료를 대체하는 경로, 전투, 판매, 강화, 스토리 보상은 반영하지 않았으며 실제 조합식의 완성률이나 클리어율이 아니다.

### 다음 검증의 제안 범위 — 아직 미구현

- 사용자가 지정한 최종 보스 등장 기준(싱글 5/10/15분, 협동 20/30분)에 맞춰 기준 맵을 선정하고 시간대별 수입·강화 지출·실제 뽑기 횟수를 함께 측정한다. 보스전 제한시간은 별도 미정이며, 협동에서는 스토리 성공 보상이 이후 성장과 성공률을 높이는 효과도 포함한다.
- 후보 기본 재료군과 조합식에 대해 목표 시점까지 재료를 갖출 확률, 실제 조합 시점, 다른 유닛에 재료를 사용한 비용과 목표 전환 가능성을 비교한다. 특정 목표의 완성률과 대체 목표 중 하나라도 완성하는 비율을 구분한다.
- 조합만 서두르는 전략, 방어·강화를 우선하는 전략, 재료에 따라 목표를 전환하는 전략, 스토리 파견 전략을 여러 난수 조건에서 비교한다. 조합 기회가 있었는지와 실제로 조합했는지도 구분한다.
- 맵별 배치 수·사거리·경로, 적 밀도·체력·속도, 보스 요구 전력, 개인 방어와 파견 손실을 함께 검증한다. 아직 구현하지 않은 사거리·배치 규칙을 현재 시뮬레이터가 검증한 것으로 취급하지 않는다.
- 계정의 조합식 해금 상태와 파티 인원별로 개인 생존·팀 생존·스토리 성공·실패 시점을 구분한다. 자동 전략의 성과는 사람의 승률이나 재미 검증을 대체하지 않는다.
- 확장 방식은 기존 뽑기 대상을 유지하면서 새 조합 전용 유닛을 추가하는 방식을 우선 검토한다. 기본 종류별 등장 확률을 보존해도 조합의 유용성·승률까지 보존되는 것은 아니며, 개조·특급도 추첨 대상에 추가하면 해당 등급의 개별 확률이 달라진다. 도감 등록만으로 뽑기 대상이 자동 확장되지 않게 분리하는 것은 후속 구현 제안이다.
