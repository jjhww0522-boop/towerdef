# 기동 훈련: 대사·배치와 검증 기록

날짜: 2026-09-23. 기준: 현재 `shared/content.json`, `playtest/app.js`의 `renderTutorial()`, 튜토리얼 core 계약. 이 문서는 실제 흐름과 후속 UI 검토 기준을 구분한다.

## 실제 흐름

- 별도 1인 훈련, 전장 3칸, 엔진 무료, 원정 크레딧·스테이지 해금 보상 없음. 완료 여부를 기록하며 다시 훈련할 수 있다.
- 안내 로봇은 **토비**. 기존 패널봇(`wei_guard`)의 공용 그림을 사용한다. 안내 초상은 전장의 로봇 수에 포함하지 않는다.
- `boss_ready`까지는 아무리 오래 읽어도 적·보스·채굴 진행·시간 초과가 발생하지 않는다. 뽑기의 7틱 대기시간은 유지한다.
- `보스전 시작`을 누른 뒤 8초 후 보스가 나타난다. 이후 실제 전투와 제한시간이 진행되며, 모든 팝업을 열 때 자동으로 멈추는 기능은 없다. 필수 설명은 시작 전과 처치 후에 둔다.
- 완료 후 안내는 **한 화면**이다. 세 개의 별도 다음 창을 추가하지 않는다.

## 목표 조립과 네 번의 뽑기

목표는 **렌즈봇 + 코일봇 → 렌즈아이** (`make_cheng_yu`). 기본 2기에서 개조 1기로 만드는 기존 조립식이며 초기부터 사용 가능해야 한다.

| 순서 | 로봇 | 역할 |
|---|---|---|
| 1 | 렌즈봇 `wei_archer` | 처음 선택하고 조립 때 다시 선택할 기준 로봇 |
| 2 | 패널봇 `wei_guard` | 남겨 두고 보스전에서 감속 지원 |
| 3 | 점화봇 `wu_archer` | 이번 훈련에서 판매할 예비 로봇 |
| 판매 | 3번째 점화봇의 실제 인스턴스 | 배치가 3/3에서 2/3으로 줄고 고철을 반환 |
| 4 | 코일봇 `wu_guard` | 마지막 재료. 판매로 빈자리가 된 칸에 생성 |
| 조립 | 처음 뽑은 렌즈봇을 선택 | 렌즈봇과 코일봇이 사라지고 렌즈봇 자리에 렌즈아이 생성 |

현재 조합식에서 최초 3기로 가능한 조립은 없고, 점화봇 판매 후 코일봇을 얻으면 목표 조립식만 완성 가능하다. 슬롯은 0·1·2, 네 번째는 빈 2번 슬롯을 사용한다. 일반 원정의 로봇·빈자리 무작위 규칙과 구분되는 훈련 전용 결과다.

렌즈봇과 렌즈아이의 사거리는 모두 520이다. 조립 시 공격력은 8에서 28로 높아진다. 사거리가 늘었다고 설명하지 않는다. 420×220 훈련장에서 세 슬롯 모두 보스 경로 전체에 사거리가 닿는다. 보스는 720HP이며 실제 자동 공격으로 처치한다.

## 현재 안내와 실제 행동

다음은 구현 상태별 현재 문구다. 제목과 설명을 한 번에 읽으며, 한 단계에서 필요한 행동만 강조한다. 제목·설명을 합쳐 물리적으로 2줄에 들어가는지는 모바일에서 별도로 확인해야 한다.

| 상태 | 현재 제목 / 설명 | 다음 행동 |
|---|---|---|
| `intro` | 지구의 자원이 바닥났어. / 다른 행성에서 자원을 구하자. 내가 도와줄게! | 같이 해보자 |
| `summon` | 첫 로봇을 깨워볼까? / 아래의 로봇 뽑기를 눌러봐. | 로봇 뽑기 |
| `inspect` 선택 전 | 렌즈봇을 눌러봐. / 조립 방법을 살펴보자. | 렌즈봇 또는 렌즈봇 선택 버튼 |
| `inspect` 선택 후 | 코일봇 1기가 부족해. / 이제 재료를 더 뽑아보자. | 재료 찾기 |
| `fill` | 재료를 더 뽑아보자. 또는 한 번 더 뽑아봐. / 훈련장에는 로봇이 들어갈 자리가 3칸이야. | 로봇 뽑기, 두 번 |
| `sell` 선택 전 | 자리가 꽉 찼네! / 지금 필요 없는 점화봇을 눌러서 팔아보자. | 점화봇 또는 점화봇 선택 버튼 |
| `sell` 선택 후 | 관리·상세 → 판매 / 팔면 자리와 고철을 얻어. | 실제 관리·상세 → 판매 → 반환량 확인 → 확정 |
| `replacement` | 빈자리 확보! / 로봇 뽑기를 눌러 코일봇을 받아봐. | 로봇 뽑기 |
| `combine` 선택 전 | 이제 재료가 모였어. / 렌즈봇을 다시 눌러봐. | 렌즈봇 선택 |
| `combine` 선택 후 | 렌즈아이로 조립! / 재료 2기가 합쳐져. 선택한 로봇의 자리는 그대로야. | 조립 |
| `boss_ready` | 보스에게는 집중 화력! / 렌즈아이는 멀리 있는 적 한 기를 공격해. 보스를 막아보자. | 보스전 시작 |
| `countdown` | 보스 등장까지 N초 / 시간이 되면 마지막 보스가 나타나. 공격은 자동이야. | 8초 후 보스 등장 |
| `boss` | 폭주 압축기를 막아! / 위의 체력 막대를 봐. 제한 시간 안에 쓰러뜨리면 성공! | 실제 보스 처치 |
| 완료 | 출발 준비 완료! / 행성을 탐험하며 로봇을 키워보자. 스테이지를 깨면 새로운 조합이 열려! | 첫 행성으로 또는 훈련 다시 하기 |

판매 반환량은 실제 상태에서 가져온다. 현재 기본 뽑기 20·반환 비율 35%에서는 7고철이다. 클릭만으로 다음 단계에 가지 않고 생성·판매·소모·보스 처치 결과를 확인한다.

## 짧은 대사·배치의 후속 검토 기준

이 절은 아직 모두 구현됐다고 주장하지 않는 UI 개선 기준이다.

- 마스코트 대사는 한 행동, 최대 2줄을 목표로 한다. 긴 상태는 예를 들어 `코일봇 1기가 더 필요해. / 재료를 더 찾아보자!`, `두 재료가 하나로 합쳐져. / 선택한 자리는 그대로야.`로 줄일 수 있다. 원래 로봇명·부족 수량·조립 조건은 유닛 요약에 남긴다.
- 판매는 상태가 바뀌지 않아도 실제 관리창에서 판매 버튼과 확정 금액을 차례로 강조한다. 판매 확정 전에 로봇이 사라진다는 설명을 유지한다.
- 완료는 한 화면 안에서 탐험·강화·해금을 안내한다. 현재 문구에 강화 범위를 더 명확히 하려면 `전투 중 강화는 이번 원정에만 적용돼요.` 한 줄을 추가하는 안을 검토한다. 실제 해금 정책에 없는 영구 능력 향상이나 튜토리얼 보상을 약속하지 않는다.
- 시작 전에 `훈련은 고정 뽑기 · 실제 원정은 랜덤`을 표시한다(구현 완료).
- 전장을 밀어내는 하단 띠를 추가하지 않는다. 390px 세로 기준 말풍선 폭 약 366px, 대사 17–18px·줄높이 24px, 초상 40–48px, 버튼 높이 48px부터 검토한다.
- 대사와 유닛 요약을 각각 큰 상자로 쌓아 실제 로봇·뽑기·조립 버튼을 가리지 않는다. 설명 영역 30dvh를 기준으로 조정하고, 짧은 가로 화면에서는 긴 내용을 단계별로 보여준다. 글자 축소로 해결하지 않는다.
- `1/3 → 2/3 → 3/3 → 2/3 → 3/3 → 2/3` 변화를 같은 위치에서 읽게 한다. 꽉 찼을 때는 뽑기 비활성화 이유를 `자리 부족`으로 표시한다.
- 강조는 목표 하나에 테두리·화살표·짧은 이름을 함께 사용한다. 동작 줄이기와 무음에서도 목표와 완료를 이해할 수 있어야 한다.

## 스크린리더·조작 주의

- Canvas 터치만 강제하지 않는다. 실제 대상 인스턴스를 선택하는 `렌즈봇 선택`·`점화봇 선택`과 로봇 목록을 사용할 수 있어야 한다.
- 새 단계는 짧은 상태 안내로 한 번만 읽는다. 폴링마다 반복 낭독하거나 초점을 강제로 옮기지 않는다.
- 관리창을 열면 초점을 안으로 이동하고 닫으면 원래 대상으로 되돌린다. 강조용 투명층이 버튼 터치를 가로채지 않게 한다.
- 비활성 이유와 부족 재료를 글자로 남긴다. 색만으로 가능·부족·선택을 구별하지 않는다.
- 카운트다운은 매초 낭독하지 않는다. `8초 뒤 보스가 나타납니다`와 `보스 등장`을 구분한다. 보스전 시작 후 제한시간은 실제로 진행됨을 숨기지 않는다.
- 360×640·390×844·667×375에서 줄 수, 버튼 접근, 판매 확정, 기준 유닛 선택을 확인한다. 스크린리더·실제 휴대폰 검증은 자동 core 검사와 별개다.

## core 검사 기록

`tests/tutorial.test.mjs`의 12개 검사가 통과했다. 별도 1인/무보상 상태, 잘못된 단계 진행, 뽑기 대기시간, 강제 뽑기와 3칸 제한, 재료 보호 판매, 기준 자리 조립, 재전송 중복 방지, 읽기 단계 1천만 틱 경계, 준비 후 8초, 세 자리 사거리, 실제 공격 처치, 중도 이탈과 정상 게임 분리를 확인했다.

이 결과는 HTTP·프로필 완료 기록·엔진 차감 검증이나 실제 모바일 사용성 검증을 대신하지 않는다.

## 최종 화면 확인

360×640·390×844·667×375에서 튜토리얼 브라우저 9개 검사를 통과했다. 실제 Canvas 로봇 중심을 터치하며 안내/요약이 목표를 가리지 않는지 확인했다. 짧은 가로 화면에서는 안내 초상과 단계 부제를 숨기고 행동 문구와 버튼을 유지한다. 다른 재료인 코일봇을 고르면 훈련 조립 버튼을 비활성화하고 처음 렌즈봇을 선택하도록 안내한다. 단위 core 검사는 12개 통과했다.
