# 폐품 로봇과 모바일 전투 화면

후속 요청: 이 문서의 고정 30dvh 화면은 첫 구현안이다. 사용자는 평소 설명·목록을 접고 기능 터치나 이벤트에 맞춰 정보를 보여주는 방향을 원한다. 30%는 최대 높이이며 상시 점유 목표가 아니다. 분위기는 밝고 귀여운 폐품 로봇과 거칠고 묵직한 우주 생존을 함께 살린다. 최신 합의는 `../GAME_DESIGN.md`와 `../LATEST_HANDOFF.md`를 따른다.

사용자 요청: 휴대폰에서 하단 설명 영역을 보이는 높이의 30% 이내로 줄이고, 글자와 설명을 더 명확하고 간단하게 만든다. 삼국지 대신 우주·폐품·조합 콘셉트로 발전시킨다. 기존의 자율 제작 위임에 따라 아래 안을 구현한다.

## 선택한 안

- 하단 전체 조작 영역과 선택 유닛 상세창에 같은 30dvh 높이 예산을 적용한다. 두 창을 쌓지 않는다. 글자를 일괄 축소하지 않고 목록을 가로로 탐색하며 상세 정보만 펼친다.
- 전장을 주 화면으로 유지한다. 자원·웨이브는 상단, 동료와 공동 스토리는 작은 요약과 선택 가능한 상세 화면으로 제공한다.
- 이름만 변경하는 안은 외형과 규칙 설명이 어긋나므로 로봇 그림과 우주 정거장까지 함께 바꾼다. 전투 능력 자체의 개편은 이번 범위에 넣지 않는다.
- 시각 방향: 민트색 우주 정거장과 크림색 조작 패널, 노란 수거 버튼, 생활 폐품으로 조립된 친근한 로봇. 제작 계열에 따른 보조 색은 식별에만 사용한다.
- 정보 순서: 전투 → 수거·선택 → 결과 이름·필요 재료·조립 → 선택적으로 수치와 다른 사용처 확인.
- 움직임: 기존 실제 공격 신호에 연결된 로봇 동작, 선택 표시, 빠른 조작창 전환을 유지한다. 움직임 줄이기를 존중한다.

## 범위와 데이터

27종의 표시 이름과 아트, 3개 스토리 이름, 제작 계열·차체·코어 표시를 교체한다. 기존 데이터 ID, 조합 관계, 태그 키, 확률, 강화 효과와 전투 수치는 유지해 기존 경기 규칙과 테스트를 보존한다. 표시에는 내부 호환용 삼국지 ID를 노출하지 않는다.

기본 분위기는 밝고 귀여운 폐품 로봇이다. 사람들의 거부감이 실제로 적다는 결론은 내리지 않는다. 실제 이용자 선호도 검증은 별도다.

## 작업과 검증

1. 모바일 화면과 짧은 문구 구현 → 세로·가로 휴대폰 뷰포트에서 하단 30% 이하, 화면 넘침 없음, 주요 터치 영역 44px 이상 확인.
2. 콘텐츠와 전장 그림 전환 → 모든 유닛 그림 로드와 이름·태그 일치 확인.
3. 회귀 확인 → 기존 서버·클라이언트 테스트, 실제 브라우저 수거·조립·강화·스토리 선택 흐름 확인.

브라우저 크기 검사는 실물 아이폰에서의 가독성·성능·사용성 검증을 대신하지 않는다. 결과는 완료 후 최신 인계에 기록한다.
