# 모바일 홈과 전장 조작 개편

사용자의 테스트 피드백에 따라 홈 → 행성 선택 → 전투를 분리한다. 기존 자율 개발 승인을 이어받아 화면 개편을 진행했다. 시설 방어의 도착 후 공격 방식은 사용자가 **시설 앞에 멈춰 계속 공격**으로 선택했다.

## 설계

- 홈은 우주 배경과 기존 대표 로봇, 출정 버튼이 중심이다. 연구 크레딧·설계도 연구·설정·이전 전장 복귀를 제공한다. 아직 없는 상점이나 영구 능력 강화는 동작하지 않는 버튼으로 넣지 않는다.
- 행성 선택은 목적지와 소요 시간, 승리/패배 조건을 보여준다. 출발은 선택 후 명시적으로 실행한다. 협동 방 참가와 연습 배속은 이 화면의 보조 기능이다.
- 별도 기지 화면을 필수 경유하는 4단계와 기존 단일 화면에 모든 기능을 모으는 방식보다, 3단계와 선택적 연구소 대화상자를 사용한다.
- 전투 하단의 분리된 띠를 없앤다. 뽑기는 전장 오른쪽 아래, 관리 버튼은 왼쪽 아래, 협동 정보는 위쪽 가장자리다. 팝업을 열어도 전장의 크기는 바뀌지 않는다. 모든 조작 대상은 최소 44px, 유닛 정보는 화면 높이 30% 이내다.
- 전장 배경을 화면 비율에 맞게 그려 검은 여백을 줄인다. 공통 전투 좌표는 유지하여 화면 비율이 실제 사거리나 배치 운을 바꾸지 않는다.
- 규칙은 목표와 실패 조건을 짝짓는다. 첫 행성은 기존 적 과밀/보스 처치, 후속 후보는 채굴기 생존/채굴 완료와 엔진 생존/충전 완료다. 시설 체력은 개인별로 관리하며 동료 라인 공격이나 자동 구조는 추가하지 않는다.

## 구현과 확인 순서

1. 홈/행성 선택 내비게이션과 연구·복귀·협동 참가 연결 → 브라우저에서 세 화면과 뒤로가기 확인.
2. 전장 안의 버튼, 화면 비율, 정보 상자 배치 → 세로/가로/데스크톱에서 겹침과 44px 터치 영역, 30% 상자 제한 확인.
3. 결정한 시설 규칙을 서버·콘텐츠·표시에 연결 → 실제 피해/패배/승리/개인별 격리를 검증.
4. 기존 뽑기·조립·강화·판매·협동 검사와 빌드 실행 → 인계 문서 갱신, 커밋/푸시, 새 미리보기 제공.

아트는 현재 제작된 로봇과 행성 표현을 재사용한다. 이번 화면 작업에 결제나 상점 상품, 최종 유닛 로스터 변경을 포함하지 않는다.

## 구현 결과: 0.7.0-expedition-siege

- 홈과 목적지 선택을 실제로 분리했고, 연구소·함께하기·이전 전장 복귀·귀환을 연결했다. 목적지 선택만으로 방을 생성하거나 재화를 소비하지 않는다. 해금 상태는 기존 서버 프로필을 따른다.
- 전장은 상단 HUD 아래부터 화면 하단까지 채운다. 설명/관리 창은 전장의 공간을 차지하지 않는다. 가로/세로 전장 비율에 맞게 배경을 그리되 공통 전투 좌표와 사거리 판정은 유지한다. 진입 표시와 진행 화살표도 회전에 맞춘다.
- 첫 행성은 기존 과밀/보스 규칙을 유지한다. 두 번째는 채굴 완료 시 즉시 클리어하여 최대 26:40이며 보스가 없다. 세 번째는 엔진을 보호하고 보스를 처치해야 하며 최대 30:06이다. 새 싱글/협동 시간표는 이 작업에서 적용하지 않는다.
- 후속 두 행성에는 과밀 패배를 적용하지 않는다. 시설 체력은 각각 24,000, 일반 적의 피해는 1초마다 각각 4/5, 보스는 6배다. 적은 경로 85% 지점에서 멈춰 각자 공격하며 처치해야 사라진다. 냉동은 도착 시간만 늦춘다. 시설 파괴와 완료가 같은 틱이면 파괴를 우선하며, 파괴된 플레이어는 그 틱의 스토리 보상을 받지 않는다.
- 클라이언트는 서버 체력·공격 중인 적 수·피격 시각을 표시하고, 시설 파괴의 패배 이유를 결과에 설명한다. 적 무리의 작은 그리기 오프셋은 시각 구분만 위한 것으로 실제 타격 좌표를 변경하지 않는다.
- 자동 전략의 조립 재료 ID를 객체로 취급하던 기존 오류를 고쳐 실제 재료 슬롯으로 사거리 도달률을 비교하도록 했다. 이전 버전 시뮬레이션 수치를 이번 난이도의 근거로 사용하지 않는다. 시설 수치는 별도 사람 플레이 검증 전의 시험값이다.

## 검증 기록

- 빌드 및 전체 Node 112검사 통과. 도착 후 정지/반복 타격, 냉동, 사망 후 피해 중단, 개인별 격리, 시설 파괴와 완료의 우선순위, 보상 제외, 채굴 즉시 완료, 엔진 보스와 과밀 규칙 분리를 포함한다.
- 모바일 7조건의 터치/배치 검사, 브라우저 품질 26검사, 위치/조립 3조건, 원정/연구 19검사, 전투 연출 8검사 통과.
- 새 화면 흐름 5화면 크기 및 후속 시설 2종의 실제 브라우저 요청과 표기를 검사했다. 후속 행성 검사는 격리된 서버의 해금/적 배치 상태를 제어하며 실제 이용자의 클리어 기록을 만들지 않는다.
- `artifacts/mobile-flow-*.png`, `mobile-flow-report.json` 및 기존 브라우저 보고서는 Git 제외 대상이다. 화면을 직접 검토했다. 자동 검사와 PC 브라우저 캡처는 실기 아이폰 성능·장시간 재미·승률 검증을 대신하지 않는다.
- 현재 로컬 확인용 7353 서버는 `.towerdef-data/mobile-preview.json`에 별도 기록을 저장한다. 기존 프로세스의 기록 파일과 동시에 쓰지 않기 위한 개발 세션 구성이다. 일반 실행은 README의 기본 서버와 저장 경로를 따른다.
