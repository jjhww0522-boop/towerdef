# 전투 화면과 액션 감각 보완

사용자의 지적은 기능의 수보다 실제 전투의 시각적·조작적 설득력이 부족하다는 것이다. 기존 자율 구현 승인 아래, 개인 방어·공동 스토리·조합과 연구 흐름을 유지하며 전투에 집중한다.

시각 방향: 귀여운 폐품 로봇이 묵직하게 싸우는 산업용 우주 채굴 현장. 어두운 철제 지형 위에 로봇의 민트·청색·주황색을 구분하고, 호박색으로 주요 행동과 채굴 장치를 강조한다. 전장이 화면의 주인공이며 작은 대시보드 카드나 커다란 빈 협동 패널을 줄인다.

콘텐츠 구성: 상단에는 웨이브·고철·병력, 전장에는 실제 로봇·적·채굴 장치와 상황 경보, 하단에는 수거·조립·강화 및 공동 스토리 진입만 둔다. 상세 설명은 사용자가 여는 창에서 보여주며 관리/로봇 창의 높이 30% 상한을 지킨다.

움직임 방향: (1) 발사 준비와 반동에서 탄도·명중·잔해까지 원인과 결과가 이어진다. (2) 새 로봇과 조립 결과는 짧은 착지·기동으로 존재감을 준다. (3) 웨이브와 탈출 보스의 등장은 짧고 비차단적인 경보로 전달한다. 움직임 줄이기·무음에서도 전투 정보를 보존한다.

1. 실제 공격 역할 → 단일 사격, 근접 군집 폭발, 근접 연쇄 전격을 서버에서 구분하고 실제 타격 대상과 위치를 전달한다. 검증: 역할별 피해/대상/처치 보상, 개인 구역 격리, 결정성, 중복 이벤트 테스트.
2. 전장·HUD·음향 → 큰 전장과 대비가 분명한 로봇, 반동/투사체/피격/파괴, 제한된 효과음, 과밀/보스 정보. 검증: 실제 브라우저 공격·조립 장면, 모션 감소/무음, 오류 및 프레임 관찰.
3. 모바일 회귀 → 세로/가로 화면의 하단 상한·44px 조작·관전/파견·조립/강화 확인, 기존 진행 테스트. 결과와 미검증인 실제 기기 성능·장시간 난도를 별도로 기록한다.

이번에는 신규 경제·보스 부위·협동 공정 등 별도 규칙을 모두 추가하지 않는다. 공격 역할 수치는 플레이 검증을 위한 초깃값이며, 연출 개선을 재미나 상업성의 검증과 동일시하지 않는다.

## 구현 결과

0.5.0에서 세 무기 패턴·실제 타격 위치/피해, 큰 전장과 강철색 HUD, 반동/탄도/폭발/연쇄/잔해, 기체 착지, 비차단 경보와 보스 체력, 제한된 합성 효과음을 구현했다. 고정 지형과 SVG 프레임을 캐시하고 등급 표시를 도형으로 바꾸어 반복 렌더링 비용을 줄였다.

전체 Node 96, 모바일 7조건 260, 브라우저 기본 8·품질 26·원정 19·전투 연출 8검사가 통과했다. 대량 전투의 프레임 중앙값은 개발 PC 자동 브라우저 관찰에서 개선됐으나 순간 지연이 남는다. 아이폰 성능과 사람의 장시간 재미·밸런스 검증은 후속 작업이다. 구체적인 수치와 실행 방법은 최신 인계 문서에 남긴다.
