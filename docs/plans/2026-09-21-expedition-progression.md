# 행성 원정·연구·모바일 조작 구현

사용자가 2026-09-21까지 논의한 내용을 구현하도록 승인했다. 기존 변경을 보존하며 브라우저 프로토타입의 실제 플레이 흐름을 완성한다. 결제·외형 상점은 구현하지 않는다.

1. 행성 전투와 조합 성장 → 첫 행성은 짧은 학습 원정, 후속 행성은 약 30분. 개인 방어와 공동 스토리를 유지하며 채굴 완료 후 탈출 보스를 상대한다. 무료 상위 경로와 재료를 공유하는 궁극 조합, 손실을 감수하는 해체를 추가한다. 검증: 서버 타이밍·소모·파견·행성 난도 테스트와 시뮬레이션.
2. 연구 크레딧과 설계도 → 판내 고철과 구분하고, 개인 종료 시 성과를 정산한다. 클리어로 다음 행성/연구 자격을 열고 크레딧으로 설계도를 선택 해금한다. 서버가 보상·잔액·해금을 검증하고 로컬 파일에 저장한다. 기본 속도의 원정만 보상하며 빠른 연습은 보상하지 않는다. 검증: 중복 정산·구매·잔액 부족·잠긴 행성·재시작 보존 테스트.
3. 모바일 화면 → 기본 하단은 얇은 행동 바. 로봇·조립·강화는 탭으로 열고, 강화 효과 확인과 구매는 분리한다. 목표 조합의 전체 경로를 필요할 때 확인한다. 검증: 실제 브라우저 흐름, 세로/가로 화면, 하단 30% 상한 및 안전영역.
4. 통합·인계 → 기존 검증을 새 동작에 맞추고 4인 방과 개인 결과/연구 흐름을 확인한다. 구현된 범위와 아직 필요한 실제 기기·장시간 사람 플레이·서비스 저장소 검증을 구분하여 기록한다.

수치와 최종 난도는 검증용 초깃값이다. 게임의 성공이나 30분 플레이의 재미가 검증됐다고 취급하지 않는다. 프로필의 로컬 영속 저장과 실행 중 전투의 재시작 복구는 별개이며, 후자는 이번 구현 범위에 없다.

## 구현 결과

행성 최대 길이는 8:12 / 28:10 / 30:06, 로봇 29종·조합 20개다. 신규 고철거신은 무료 조합이며 성운방주는 연구가 필요한 궁극 조합이다. 해체 시 누적 수거 투자액의 35%를 회수한다. 연구 자격은 해당 행성 클리어로 얻고 실제 해금에는 연구 크레딧을 사용한다. 소환 확률은 기존 93%/6.8%/0.2%를 유지한다.

보상은 개인 종료 결과에 고정한다. 참여·처치가 있는 원정에서 채굴 구간과 클리어에 따라 산정하며 이탈·무입력·연습은 보상하지 않는다. 프로필의 인증·잔액·연구·중복 정산 방지는 서버에 있으며 CLI 실행에서 파일로 영속 저장한다. 운영용 계정 및 Nakama 진행 이식은 별도다.
