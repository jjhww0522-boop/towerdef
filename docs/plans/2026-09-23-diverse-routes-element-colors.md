# 다양한 진입 경로와 속성 색상
## 사용자 지시
사각 순환만 있는 챕터를 세로·가로 직선, 양방향, 십자형으로 다양화한다. 길 양옆의 배치 가능 위치가 직관적으로 보이게 한다. 로봇은 속성별 색상(화염 빨강, 냉동 파랑 등)으로 디자인한다.

## 구현 설계
1. 착륙 지대는 기존 순환, 채굴장은 위→아래, 엔진 기지는 왼쪽→오른쪽, 협곡은 양쪽→중앙, 탈출항은 네 방향→중앙 시설. 2~5는 열린 길이며 도착한 적은 기존 사용자 선택대로 멈춰 시설을 계속 공격한다. 4의 적체 목표는 시설 보호로 바뀐다.
2. 여러 입구는 같은 총 적 생성량을 분배한다. 적마다 경로 번호를 고정하고 사거리·폭발·연쇄·공격 연출이 실제 위치를 따르도록 한다. 서로 다른 입구의 같은 진행률을 같은 위치로 취급하지 않는다.
3. 새 맵은 720×720 전투 좌표를 사용하며 화면 회전에도 진입 방향을 유지한다. 1번의 기존 좌표·회전은 보존한다. 화면 사거리 표시는 투영 비율을 따른다.
4. 배치 가능 위치를 밝은 받침대와 모서리 표시로 보여준다. 비어 있는 곳만 뽑기 후보임을 뽑기 누름/선택 안내에서 짧게 보여준다. 수동 설치/이동은 추가하지 않는다. 랜덤 소환과 선택 위치 조립 유지.
5. 화염 빨강/주황, 냉동 파랑/청록, 바람 민트, 레이저 보라, 전격 노랑. 본체/무기/발광부/공격효과/초상/홈이 공용 팔레트를 사용한다. 생활용품 실루엣과 금속/손잡이/눈의 대비는 유지한다.
6. 엔진·결제·연구·뽑기 확률·조합식은 유지한다. 1~3 시간과 4/5 보스 시각도 유지한다. 새 동선에 필요한 난이도 보정은 검증 결과와 함께 기록한다.

## 순서와 검증
- 공용 지도/서버 → 열린 끝점, 고정 경로 분배, 다중 진입 사거리/범위 공격, 시설 공격, 협동 각자 방어 검사.
- Canvas/배치 표시/팔레트 → 모든 경로와 입구가 보이고 슬롯과 적 길이 분리되며 공격 연출이 해당 경로를 향하는지 확인.
- 모바일 세로/가로 5개 지도, 로봇 선택/조립, 화면 고정, 속성별 대표5종 캡처.
- 빌드·회귀·자동 플레이 검증, 개발 서버 갱신, 문서/커밋/푸시.

변형 순환만 유지하면 실제 동선 차이가 작다. 무작위 길 생성은 검증할 조합이 크게 늘어나므로 이번에는 사용자 요청의 고정된 다섯 경로를 구현한다.
