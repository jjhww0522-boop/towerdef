# 6속성 생활 장비 로봇 — 속성별 4단계와 공통 최종 S

2026-09-27 갱신. 사용자 요청: 실생활 물건을 바탕으로 한 6속성을 유지하고, **각 속성의 1→2→3→4단계가 동일한 5단계 S 한 종류로 합류**한다. 이후 업데이트에서 `a3+b3+c3→z4` 같은 특수 조합을 추가한다.

이 문서는 기존 5속성안, 29종 이름 교체 후보, 직전 6속성·3단계·18종안을 대신하는 **최신 유닛 설계 기준**이다. 사용자의 실행 지시에 따라 `0.13.0-six-elements`부터 아래 25종·24식을 실제 콘텐츠에 적용한다. 기본 6종만 소환하며 동일 3기 조합을 사용한다. 챕터 1에서는 3단계까지만 해금하고 4단계/S는 후속 업데이트로 표시한다. 적용 범위와 검증은 [실행 계획](../superpowers/plans/2026-09-27-six-element-rollout.md)과 최신 인계를 함께 확인한다.

사용자가 정한 것은 6개 속성별 4단계, 공통 5단계 한 종류, 후속 특수 조합이다. 이후 ‘계획한대로 유닛들 변경, 난이도조절’ 지시에 따라 **같은 유닛 3기 조합과 아래 이름·초반 해금**을 적용했다. 미래 4단계/S의 실제 해금 콘텐츠는 후속 작업이다. ‘S 한 개’는 종류가 하나라는 뜻으로 해석하며 전장당 1기 제한을 추가하지 않는다.

## 새 전체 목록

기존 화염·냉동·바람·전격·레이저에 **물**을 추가한다. 물은 수압과 물줄기, 냉기는 냉각과 감속으로 구별한다. 표시 속성은 화염·물·냉기·바람·전기·레이저로 통일하는 안이다.

| 속성 / 데이터 키 | 1단계 | 2단계 | 3단계 | 4단계 | 전투 역할의 방향 |
| --- | --- | --- | --- | --- | --- |
| 화염 / `fire` | **라이터** | **가스레인지** | **화염방사기** | **소각로** | 짧은 사거리의 강한 화염 공격 |
| 물 / `water` | **물총** | **세차 호스** | **고압세척기** | **소방차** | 중거리의 곧은 물줄기·연속 분사 |
| 냉기 / `frost` | **소형 냉장고** | **제빙기** | **급속냉동고** | **냉동창고** | 냉각 출력 증가·감속을 동반한 공격 |
| 바람 / `wind` | **휴대용 선풍기** | **선풍기** | **산업용 송풍기** | **제트엔진** | 더 넓은 범위에 바람 피해 |
| 전기 / `electric` | **건전지** | **전기모기채** | **고압변압기** | **발전소** | 방전 공격, 상위에서 연쇄 효과를 강조 |
| 레이저 / `laser` | **레이저 포인터** | **레이저 조각기** | **레이저 절단기** | **레이저포** | 긴 사거리의 집중 단일 공격 |

여섯 계열의 마지막은 모두 **5단계 S — 만능 수호로봇(가칭)**이다. 총 **6종 × 4단계 + 공통 S 1종 = 25종**이다. 속성마다 다른 S 여섯 종을 만드는 구조가 아니다. 혼합식은 여섯 계열의 단일 성장과 실전 역할이 검증된 뒤의 확장으로 남기며 초기 25종에 포함하지 않는다.

## 이름과 등급을 정한 이유

- 화염은 사용자가 제시한 세 이름을 그대로 두고, 4단계에 연소실과 투입구를 가진 소각로를 더한다.
- 물은 장난감 분사 → 호스의 지속 공급 → 고압 장비 → 물탱크·펌프·방수포를 갖춘 소방차로 확장한다. 고압세척기보다 모든 소방차의 수압이 높다는 의미는 아니다.
- 냉기는 작은 냉각 장치 → 제빙 → 급속 동결 → 공간 전체를 냉각하는 냉동창고로 커진다. 얼음틀·얼음팩은 출력 장치가 아닌 수동 물건이라 제외했다.
- 바람은 팬에서 대형 공기 분사 장치로 성장한다. 제트엔진은 흡기구와 공기 흐름을 강조해 화염 계열과 구별한다.
- 전기는 익숙한 전원 → 방전하는 도구 → 변압 장비 → 전력을 생산하는 발전소를 전투 로봇으로 개조한다. 실제 제품의 전압·소비전력·위험도가 곧 등급이라는 설명은 하지 않는다.
- 레이저는 포인터 → 조각 → 절단 → 목표를 조준하는 레이저포로 역할이 커진다. 실존 레이저대공무기라는 장비 범주를 참고하되 특정 제품의 이름·외형·성능을 복제하지 않는다.

4단계는 생활 소품에서 **대형 산업 장비·시설·실존 장비**로 범위를 넓힌다. 소각로·냉동창고·발전소도 축소된 몸체에 눈과 바퀴를 붙여 하나의 전투 로봇으로 표현한다. 레이저포의 실존 장비 참고는 [방위사업청의 레이저대공무기 양산 착수 발표, 2024-07-11](https://www.dapa.go.kr/dapa/doc/selectDoc.do?bbsSeq=326&docSeq=19485&menuSeq=3069)이며, 존재하는 장비 범주만 참고한다. 이미지·브랜드·기술 도면은 반입하지 않았다.

등급은 **게임 속 개조 후 전투 출력**으로 정의한다. 모든 실물 제품의 성능이 표 순서대로 높다는 주장이 아니다. 공격력·주 대상 초당 피해·대상 수·사거리·감속 기여를 따로 검증하고, 제품명만 바꿔 상위 기체가 강해졌다고 간주하지 않는다.

## 조합 경로와 공통 최종 유닛

초기 구성은 속성별 단일 성장으로 정리한다.

```text
같은 1단계 3기 → 해당 속성 2단계 1기
같은 2단계 3기 → 해당 속성 3단계 1기
같은 3단계 3기 → 해당 속성 4단계 1기
같은 4단계 3기 → 공통 5단계 S 1기

라이터 ×3 → 가스레인지
가스레인지 ×3 → 화염방사기
화염방사기 ×3 → 소각로
소각로 ×3 → 만능 수호로봇

소방차 ×3 → 만능 수호로봇
냉동창고 ×3 → 만능 수호로봇
제트엔진 ×3 → 만능 수호로봇
발전소 ×3 → 만능 수호로봇
레이저포 ×3 → 만능 수호로봇
```

총 **24개 성장식 = 속성별 1→4단계 18식 + S로 합류하는 6식**이다. 초기에는 서로 다른 4단계 세 기를 섞어 S를 만들지 않는다. 1→4단계는 표의 같은 행에서만 성장한다. 조립 후 남는 자리는 기존처럼 선택한 재료의 자리다.

공통 S는 어느 경로로 만들든 **동일한 유닛 ID·외형·능력**을 사용한다. 기존 실행 콘텐츠의 궁극 유닛과 같은 것으로 간주하거나 옛 연구를 자동 이전하지 않는다. ‘공통’은 조합의 결과가 같다는 뜻이며, 일곱 번째 기본 소환 속성을 추가한다는 뜻이 아니다.

만능 수호로봇은 여러 생활 장비를 통합한 최종 개조 로봇이라는 콘셉트다. S의 주 역할은 강한 마무리 화력으로 잡되, 이름 때문에 감속·연쇄·범위 공격 등 모든 능력을 최대 성능으로 동시에 갖게 하지는 않는다. 조립은 선택 행동으로 유지하고 4단계 지원 유닛을 남기는 판단도 가능하게 한다. 정확한 공격 방식·수치는 전투 검증에서 정하며 조립 결과의 능력을 정보창에 미리 표시한다.

## 재료 비용과 해금

**재료 환산량**은 상위 유닛 한 기를 만드는 데 들어가는 기본 유닛의 수다. 동일 3기 조합이면 다음처럼 늘어난다.

| 완성 단계 | 필요한 같은 계열 기본 유닛 환산량 |
| --- | ---: |
| 1단계 | 1기 |
| 2단계 | 3기 |
| 3단계 | 9기 |
| 4단계 | 27기 |
| 5단계 S | 81기 |

이는 재료 하한이며 실제 소환 횟수·고철 비용·완성 시간을 뜻하지 않는다. 기본 6종을 각 1/6로만 뽑는 가정에서 미리 정한 한 계열의 81기를 모으려면 기대 소환 횟수는 486회다. 여섯 경로 중 먼저 모이는 경로를 선택하는 경우의 기대값과는 다르며 실제 플레이 측정값도 아니다. 다른 계열의 잔여 재료·판매 손실·배치 칸·방어력 손실을 함께 확인해야 한다.

해금 방향은 1구역 입장부터 1→2단계 6식, 2구역 첫 클리어 뒤 2→3단계 6식, 챕터 2에서 3→4단계 6식 순서로 권한다. S는 후반 콘텐츠의 성장 목표로 두고 정확한 해금 구역은 도달 시간 검증 뒤 정한다. 이번 요청이 모든 단계를 첫 구역부터 열라는 뜻은 아니다. 챕터 1은 최고 3단계 목표를 유지하며 1·2구역은 2단계 전력으로도 충분히 통과하도록 설계한다. 1구역 최대 3분/목표 난도 1, 2구역 4분/목표 난도 1.5와 게임 전체 1~10 척도를 유지한다.

현재 전장 유닛은 원정마다 다시 만든다. 해금이 계정에 남는 것과 전장 재료가 다음 스테이지에 누적되는 것을 혼동하지 않는다. 81기라는 하한을 채우려고 초반 전투 시간을 늘리지 않는다. 후반에도 수집 시간이 지나치게 길다면 재료 수급과 마지막 조합 비용을 별도로 비교하되, 이번 문서만으로 수입·유료 상품·새 전용 재화를 추가하지 않는다.

소환은 장기적으로 기본 6종 각 1/6을 기준으로 비교한다. 기존 9종·상위 직뽑기를 그대로 두면 6종 시작 구조가 되지 않으므로, 실제 적용 시 소환·조합·훈련·해금을 함께 바꿔야 한다. 1/6은 약 16.67%이며 UI의 반올림 합을 확률 판정에 사용하지 않는다. 수입·칸 수·소환 속도는 확률 변화와 함께 검증하며 이번 이름 설계에서 임의로 낮추거나 올리지 않는다.

## 이후 업데이트: 특수 조합

**특수 조합**은 서로 다른 계열의 재료를 섞어, 기본 성장표에는 없는 유닛을 만드는 추가 경로다. 초기 25종·24식에는 포함하지 않는다.

```text
a3 + b3 + c3 → z4
z4 ×3 → 기존과 동일한 S

예시 후보:
화염방사기 + 고압세척기 + 산업용 송풍기 → 증기기관차(특수 4단계)
증기기관차 ×3 → 만능 수호로봇
```

증기기관차는 개념을 설명하는 후속 후보이며 현재 제작·출시 목록이 아니다. 기존 여섯 단일 계열을 삭제하거나 S의 필수 재료로 특수 유닛을 강제하지 않는다. 특수 4단계 한 종류를 추가하면 **26종·26식**이 된다. 이를 기본 소환 풀에 넣지 않으므로 신규 조합 때문에 기본 6종의 소환 확률이 희석되지 않는다.

특수식의 재료는 3단계 각 9기분이므로 `9+9+9=27`로 정규 4단계와 환산량이 같다. 하지만 필요한 재료가 분산되고 지원 역할을 동시에 소모하므로 실제 수집 난도·전투 가치는 같다고 단정하지 않는다. 새 특수 유닛마다 분명한 전투 역할, 발견/해금 시점, S로 이어지는 경로, 수집 비용과 조립 직후의 전력 손실을 검증한다. 무조건 더 강한 상위 정답으로 만들지 않는다.

조합 정보는 기존 사용자 요청대로 **선택한 유닛의 정보창**에서 보여준다. 당장 만들 수 있는 결과·재료 보유 수·최종 S까지의 다음 단계와 해금 조건을 구분한다. 후속 특수식도 재료로 쓰이는 유닛을 눌렀을 때만 관련 경로를 추가하고, 전투 화면 아래에 전체 조합식을 상시 나열하지 않는다.

## 물과 기존 전투의 연결

물은 새로 제안한 여섯 번째 속성이다. 중거리의 잦은 타격과 분사 표현을 우선 비교한다. 화염은 가까이 온 적에게 높은 피해, 냉기는 감속, 바람은 넓은 범위, 전기는 연쇄, 레이저는 긴 사거리 집중으로 각 계열의 역할을 구별한다.

현재 코어에 물 전용 판정은 없다. 밀치기·관통·감전 연계·속성 상성을 이름 변경에 묶어 자동 추가하지 않는다. 필요한 차별화가 실제 전투에서 부족하면 그 효과의 서버 판정·예고·수치·회귀 검사를 따로 설계한다. ‘회오리’ 이름만으로 흡입이 생기거나, ‘냉동고’가 모든 적을 완전 정지시키는 것으로 설명하지 않는다.

상위 등급의 세부 공격 방식과 수치는 새 로스터 시뮬레이션에서 정한다. 같은 계열의 재료 3기를 소모한 뒤 실전 기여가 떨어지지 않는지, 슬롯 여유와 역할 보존도 함께 확인한다. 봇 통과율과 실제 재미는 별도로 기록한다.

## 아트와 보스 재사용 수정

물건 자체가 몸이고 눈·다리·바퀴를 붙인다. 1→4단계 조합 전후에도 불꽃 출구, 호스, 냉각부, 팬, 전극, 렌즈라는 **계열의 핵심 장치**를 남긴다. 크기 확대나 색 교체만으로 네 단계를 만들지 않는다. S의 몸체·애니메이션은 한 세트로 공유하며 출신 속성마다 다른 최종 유닛 자산을 만들지 않는다.

이전 토스터·전자레인지·프로젝터 시안은 **이전 후보**로 보관한다. 새 명칭표에 그 제품을 억지로 끼워 넣지 않으며, 상위 아군과 보스가 같은 원형을 공유한다는 원칙만 이어 간다.

| 현행 구역의 보스 디자인 대응 | 새 공통 원형 | 공유할 단계 |
| --- | --- | --- |

## 현재 상태와 구현 시 함께 처리할 범위

`0.13.0-six-elements` 전환은 **25종 이름·6속성별 4단계·공통 5단계 S·24식 성장 경로**를 실제 실행 데이터로 사용한다. 특수 혼합식은 후속 설계로 남긴다. 4단계와 S의 후반 해금·도달 시간은 아직 검증된 출시 콘텐츠가 아니므로 일반 계정에서 잠근다. 아래 목록은 전환의 필수 확인 항목이며, 기존 시안은 새 25종 아트의 납품 완료 근거로 사용하지 않는다.
