# 공통 난이도 기준

기준일: 2026-09-26. 대상: 폐품로봇 원정대의 모든 스테이지와 후속 콘텐츠.
이 문서는 설계 목표다. 실제 구현값과 검증 결과는 콘텐츠 및 해당 실험 기록에 별도로 남긴다.

## 척도의 의미

- 난이도는 **1~10, 0.5 간격**의 게임 전체 공통 절대척도로 기록한다.
- 특정 챕터 안의 상대 순위가 아니다. 현재 다섯 구역을 1~10에 억지로 나누지 않는다.
- 숫자는 체력·공격력 배수나 승률이 아니다. 난이도 2가 난이도 1의 두 배 체력이라는 뜻도 아니다.
- 해당 스테이지에 처음 도달할 때 사용할 수 있는 조합·기능과 기본 속도를 평가 기준으로 삼는다.
- 구매 연구·희귀 직접 소환·이미 숙련된 최적 전략을 입문 난이도의 전제에 넣지 않는다.
- 싱글과 협동은 같은 척도를 쓰되 인원·파견 기여 등 평가 조건을 명시한다. 배속 결과를 기본 속도 체감으로 대신하지 않는다.

## 네 가지 판단 축

| 축 | 확인할 내용 |
| --- | --- |
| 학습 부담 | 새로 알아야 할 규칙과 동시에 기억해야 하는 정보가 얼마나 많은가 |
| 압박 | 적의 접근·시설 피해·제한 시간이 대응을 얼마나 자주 요구하는가 |
| 실수 회복 | 늦은 뽑기·비효율적 조립·잘못된 자원 배분 후 다시 대응할 기회가 있는가 |
| 필요한 조합 판단 | 간단한 첫 조립으로 충분한가, 아니면 역할·사거리·재료 보존을 함께 판단해야 하는가 |

네 축을 기계적으로 평균내지 않는다. 한 축의 큰 부담이 숨겨지지 않게 대표 플레이 상황과 함께 등급의 이유를 적는다.

## 등급별 기준

| 등급 | 학습 부담 | 압박 | 실수 회복 | 필요한 조합 판단 |
| --- | --- | --- | --- | --- |
| **1** | 뽑기·선택·첫 조립의 기본 흐름 | 짧고 읽기 쉬운 위협, 대응 시간 넉넉함 | 몇 번 늦거나 비효율적으로 골라도 회복할 여유 | 간단한 입력과 첫 조립 성공을 경험하며 통과. 최적화 불필요 |
| **1.5** | 시설 보호와 감속의 의미를 한 단계 추가 | 적이 시설에 닿는 결과를 볼 수 있으나 초반부터 압도하지 않음 | 소수 적 도착·늦은 대응 등 작은 실수 허용 | 사거리나 감속을 한 번 생각해 볼 정도. 모든 속성 이해 불필요 |
| **2~3** | 익힌 규칙을 조합하고 새 역할을 순차 학습 | 특정 구간에서 준비·보강이 필요 | 한두 번의 판단 착오를 이후 선택으로 만회 가능 | 단일·범위·감속 중 필요한 역할과 간단한 대체 조합을 선택 |
| **4~5** | 여러 역할·경로·자원 용도를 함께 고려 | 공세별 약점이 드러나고 계획 없는 지출에 비용 발생 | 반복 실수는 위험하지만 원인을 읽고 수정할 여유 존재 | 재료 보존·강화·사거리·후반 준비 사이의 우선순위 판단 |
| **6~7** | 익숙한 규칙의 복합 상황을 빠르게 해석 | 취약 구간이 연속되고 준비 부족이 누적 | 회복 창이 짧아 자원과 전술을 아껴 써야 함 | 중간 목표를 바꾸거나 조합·배치를 상황에 맞춰 전환 |
| **8~9** | 고급 규칙과 상황 변화에 숙련 필요 | 작은 손실도 후반 압박으로 이어짐 | 제한된 기회 안에 실수를 정확히 보완해야 함 | 여러 단계의 재료·화력·시설 방어 계획과 대안 준비 필요 |
| **10** | 게임 규칙을 깊이 이해한 숙련자 대상 | 높은 압박이 지속되되 원인·예고는 읽을 수 있음 | 의도적으로 좁은 회복 여유 | 자원·조합·사거리·전술의 일관된 최적화와 적응을 요구하는 최고 도전 |

0.5 단계는 인접 등급 사이의 부담 차이를 표현한다. 예를 들어 3.5를 부여할 때는 3에서 늘어난 판단과 4보다 남아 있는 회복 여유를 설명한다.
높은 난이도를 가독성 부족·숨은 규칙·입력 오류·필수 해금의 모순으로 만들지 않는다. 목표 조합의 성공이나 모든 판의 클리어를 보장한다는 뜻은 아니다.

## 확정된 초반 목표

| 표시 / 내부 매핑 | 목표 난이도 | 시간 설계 | 의도 |
| --- | ---: | --- | --- |
| **1-1 착륙 지대** / chapterId 1, battlefieldId 1 | **1** | 일반 방어 120초 + 보스 최대 60초 = **최대 총 3분**. 일찍 처치하면 더 빨리 종료 | 짧은 첫 승리와 조립의 재미를 경험하고 다음 구역으로 이동 |
| **1-2 채굴장** / chapterId 1, battlefieldId 2 | **1.5** | 보스 없이 채굴기 보호 **총 4분**. 시설 파괴 시 조기 실패 | 시설·감속을 배우고 작은 실수를 만회하며 통과 |

난이도 1은 무입력 자동 클리어가 목표가 아니다. 간단히 뽑고 첫 조립을 시도하는 플레이가 성공 경험으로 이어지게 한다. 첫 조립이 승리 판정의 강제 조건이라는 뜻은 아니다.
1-3~1-5 및 이후 스테이지의 난이도는 **미평가**다. 이번 시간 조정은 첫 두 구역에 한정하며 3~5번의 시간·전투 수치·난이도를 이 문서에서 변경하지 않는다.

## 확인과 기록

- 먼저 목표 등급·입장 시 해금·인원·속도를 기록하고, 첫 조립 시점·위험 구간·실수 후 회복·패배 원인을 확인한다.
- 자동 봇은 회귀·극단 조건·전략 차이를 찾는 도구다. 봇 승률이나 적이 없는 시간만으로 사람의 재미·체감 난이도를 확정하지 않는다.
- 초반의 낮은 압박과 짧은 통과는 의도된 설계다. 높은 생존율·긴 안전 구간을 없애려고 갑자기 적을 폭증시키지 않는다.
- 너무 조용하다면 먼저 첫 조립과 역할 변화가 보이는지 살핀다. 난이도 상향보다 학습 경험의 성립 여부를 먼저 확인한다.
- 실제 사람 검증이 없으면 ‘설계 목표 / 자동 확인 / 인간 체감 미검증’을 구분해 적는다. 평가 전 구역에는 추정 숫자를 붙이지 않는다.
