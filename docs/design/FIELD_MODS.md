# 현장개조 — 이번 원정의 전투 방식을 선택하기

2026-09-27 사용자 요청: 게임 구조를 더 정교하고 흥미롭게 개선한다. 기존 자동 진행 위임에 따라 대장이 설계·통합한다. 실제 인간 재미 검증은 후속이며 이번에는 플레이 가능한 변경과 규칙 검증을 제공한다.

## 판단

현재 목표 지정/부족 재료 표시는 이미 있다. 소환 운 보정은 앞으로의 5종 풀 개편과 재료 경제를 함께 바꾸므로 분리한다. 새 영구 성장·수입 조정 대신, 현재 병력과 적 예고를 보고 **하나의 조건부 공격 효과를 골라 중반에 유지/교체**하게 한다. 강화가 두 번 쌓이는 설계와 비교해 한 슬롯으로 결정했다. 5종/8맵/전체 아트의 실기기 이후 관문은 유지한다.

## 규칙과 데이터 계약

- 현행 5맵·29유닛·20조합·비용/보상·적/시간/사거리·소환 난수는 유지한다. 콘텐츠 버전은 `0.12.0-field-mods`.
- 무료 훈련에는 현장개조가 없다. 일반/연습 원정의 본진 타격만 적용하고 파견·동료 레인에는 적용하지 않는다.
- `duration = rules.waveTicks * rules.totalWaves`. `floor(duration/3)`와 `floor(duration*2/3)`에 기회가 열린다. 1구역 40/80초, 2구역 80/160초. 한 번에 한 효과만 활성화된다.
- 첫 기회 `survey`, 두 번째 `retune`. 늦게 보는 경우 최신 기회 한 개만 표시한다. 이전 선택이 없더라도 두 번째에서 선택할 수 있다. 자동 선택/강제 팝업/일시정지/타이머 페널티는 없다. 최신 기회는 개인 원정 종료까지 남는다.
- 각 기회는 한 번 확정한다. 두 번째에서 같은 개조를 고르면 유지, 다른 개조를 고르면 이전 효과를 교체한다. 상한은 두 번이며 중첩하지 않는다. 선택에 자원이나 보상 자격을 지급하지 않는다.
- 기회 전환 직전 아직 서버에 도달하지 않은 옛 요청은 명시적으로 거절한다. 이미 확정한 요청의 같은 seq 재전송은 기존 성공을 재현한다. 같은 seq의 다른 `offerId/modId`는 거절한다.

| id | 이름 | 실제 타격 직전 조건 | 추가 배율 |
| --- | --- | --- | --- |
| `tracker` | 추적 회로 | 적이 이미 감속 또는 기절 중 | +15% |
| `scatter` | 분산 노즐 | 범위/연쇄 공격의 두 번째 이후 적중 | +20% |
| `opener` | 선제 센서 | 적 현재 HP가 최대 HP의 80% 이상 | +10% |

조건부 배율은 과부하를 포함한 해당 적중의 기본 피해에 곱한다. 첫 냉동 타격 자체로 새로 부여하는 감속은 그 타격의 추적 조건이 아니다. 추가 피해는 `min(hp, boostedDamage) - min(hp, baseDamage)`로 실제 남은 HP에 맞춘다. 이 값이 양수인 타격만 `hits`를 센다. 캠페인 전체의 인과 기여나 처치 기여라고 과장하지 않는다.

공개 콘텐츠 `fieldMods:[{id,name,description,condition,bonus}]`. 개인 공개 상태 `fieldMod:null | {activeId:string|null,offerId:'survey'|'retune'|null,available:boolean,nextOfferTick:number|null,optionIds:string[],history:[{offerId,modId,tick}],stats:[{modId,hits,bonusDamage}]}`. 기회 전에는 offerId=null이고 nextOfferTick=첫 시점; 두 번째 후에는 nextOfferTick=null. `available`은 서버의 개인 활성 상태까지 반영한다. 끝난 플레이어에게는 false.

행동 `choose_mod`의 payload는 `{seq,type,offerId,modId}`. 내부 상태 구조는 서버 담당이 결정하되 공개 계약은 위와 같다. `result.fieldMod`에는 선택 이력·효과/통계를 복사하여 종료 후 동료가 싸워도 변하지 않게 한다. 저장된 과거 결과의 필드 부재는 허용한다.

## 플레이어 흐름

자동 팝업 없이 기존 조작을 가리지 않는 '현장개조' 진입을 제공한다. 패널에는 현재 효과, 세 조건, 현재 병력에서 활용할 방법, 다음 조정 시점을 표시한다. 상태 미리보기에 없는 병력은 없다고 안내하고 선택 자체를 금지하지 않는다. 효과는 서버 응답 후 확정한다. 선택 중에도 위협·소환·전술에 접근할 수 있고 로봇 정보창과 겹쳐 열지 않는다. 결과에는 고른 순서와 개조별 실제 추가 피해·유효 적중을 보여준다. 선택하지 않았다면 강화를 사용한 것처럼 꾸미지 않는다.
