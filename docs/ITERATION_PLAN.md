# 플레이테스트 반복 계획 — 2026-09-19

사용자가 제작팀의 자율적인 개발·테스트·개선 반복을 요청했다.
실제 소비자 반응은 모집한 사람이 플레이한 자료로만 기록한다.
에이전트 검토와 자동 전략 실험은 각각 내부 사용성 검토·시뮬레이션으로 표시한다.

## 이번 통과 기준

1. Unity 설치 없이 로컬 브라우저에서 소환→조합→강화→스토리→결과→재도전을 실행한다.
2. 네 개 독립 브라우저 접속이 같은 서버 상태를 보고, 이탈·재접속이 동료 판을 끝내지 않는다.
3. 핵심 선택을 안내하고, 실패 이유·다음 행동·조합 재료를 화면에서 확인한다.
4. 자동 전략 비교로 초깃값의 과도한 난도/쉬움을 조정하되 승률을 소비자 만족도로 해석하지 않는다.
5. 실제 화면·조작 검증에서 발견한 문제를 수정하고 다시 확인한다.
6. 로컬 피드백 기록·내보내기와 실제 이용자 테스트 절차를 준비한다. 외부 전송은 하지 않는다.

## 팀과 파일 소유권

- 화면 담당: `playtest/` 브라우저 UI/애니메이션/안내/로컬 피드백. 서버 판정 중복 금지.
- 전투 담당: `server/core/`, `shared/content.json`, `tools/simulate.mjs`, 전투/콘텐츠 테스트와 밸런스 결과 문서.
- QA 담당: `docs/PLAYTEST_PROTOCOL.md`, 내부 검토 보고. 완료 후 브라우저/코드 독립 검토.
- 통합 담당: HTTP 서버·보안·자동 브라우저 검증·실행 문서.

브라우저 화면은 같은 권위 코어를 사용하는 개발·사용성 검증 도구다. Unity/iPhone 제품 방향은 유지한다.
사용자의 그래픽 품질 요청에 따라 독자 생성한 로컬 PNG 원화와 Canvas/CSS 연출을 사용한다. 외부 CDN·폰트·스크립트에 의존하지 않는다. 자산 출처와 표현의 한계는 VISUAL_QUALITY.md에 기록한다.

## 서버 계약 보강

루트 `/`는 플레이테스트 UI, `/app.js`, `/style.css` 등은 `playtest/` 명시 파일만 제공.
기존 `/content`, `/session`, `/state`, `/action` 계약 유지.
로컬 동일 출처만 Origin 허용. 임의 외부 사이트와 잘못된 Host는 거부.
세션 생성 시 `speed:1|3|6` 선택 가능, 기본1. 방 생성 이후 변경할 수 없다.
표시 상태에 `playbackSpeed`를 추가하고 항상 연습임을 표시한다. 빠른 모드는 전투 스텝만 배속한다.
단절 유예는 실제 시간 120초로 보정한다. 새 플레이어의 보스 이후 입장은 기존대로 거절한다.

## 반복 기록

이전 버전: 자동 전략 6경기/36라인 모두 성공. 실제 화면 실행과 소비자 테스트 없음.
이번 반복에서는 발견→수정→재검증의 증거를 기록하고 검증하지 않은 항목은 분리한다.
