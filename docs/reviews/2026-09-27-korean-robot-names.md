# 상위 로봇 이름 검토 — 익숙한 물건과 자연스러운 한국어

**후속 결정:** 사용자 요청에 따라 [6속성별 4단계 + 공통 S의 전체 25종](../design/SIX_ELEMENT_ROSTER.md)으로 명칭·성장 체계를 다시 구성했다. 이 문서의 기존 29종 대상 교체 후보와 직전 18종안은 이전 검토 기록이다. 익숙한 물건 이름·실제 역할·하나의 대표 명칭이라는 원칙은 새 안에도 적용하며 S는 가칭 만능 수호로봇이다.

2026-09-27. 사용자 요청: 상위 로봇 이름이 한국어로 친숙하지 않고 이질적이므로 검토한다. 대장과 기획·밸런스팀이 `shared/content.json`의 상위 20종을 실제 속성·공격 방식·조합과 함께 확인했다. 아래는 **명칭 교체 권고안**이며 실행 콘텐츠·저장 ID·조합식·아트는 변경하지 않았다. 실제 사용자 선호 조사는 수행하지 않았다.

## 판단

가전·폐품을 직접 조립하는 콘셉트에 비해 현재 이름은 추상적인 영문 SF 단어를 길게 붙이는 경우가 많다. 볼트타이탄, 오비탈옵저버, 플라즈마캐스터는 이름만으로 어떤 물건인지 알기 어렵다. 볼트가드·패널키퍼·코일메이커는 보호나 생산 기능을 기대하게 할 수 있다. 특히 **스파크포·스파크펀처는 실제로 바람/범위 공격**이어서 전격 계열처럼 들리는 이름과 어긋난다.

사용자가 말한 ‘한국적’은 이번 검토에서 **한국어 사용자가 자연스럽게 부르고 실제 물건을 떠올릴 수 있는 말**로 해석했다. 전통·무협풍 세계관을 새로 도입하지 않는다. 토스터·레이저·빔프로젝터처럼 생활에서 익숙한 외래어는 사용할 수 있다. ‘수거대장·고철박사·고철거신’은 세계관에 어울리는 한국어 별명의 좋은 기준이다.

## 권장 명명 원칙

1. **물건 이름을 중심에 둔다.** 토스터, 선풍기, 전자레인지, 영사기, 송풍기, 코일처럼 모습을 짐작할 수 있는 명사를 쓴다.
2. **특징은 하나만 더한다.** 불꽃·회오리·번개·광선 등 실제 역할과 어울리는 수식어를 붙인다. 수식어 여러 개로 등급을 과장하지 않는다.
3. **상위에서도 원형을 남긴다.** 같은 제품 계열이면 조합 후에도 공통 명사를 알아볼 수 있게 한다. 현재 혼합식과 미래 동일 3기 조합의 계보는 별도로 관리한다.
4. **능력 설명은 실제 판정과 맞춘다.** 보호막·소환·아군 충전·흡입·완전 빙결을 이름으로 약속하지 않는다. ‘강력하다’는 별명과 새 기능을 암시하는 명칭을 구분한다.
5. **별명은 필요한 곳에만 쓴다.** 모든 기체를 ‘○○이·○○봇·○○대장’으로 통일하지 않는다. 귀여운 호칭을 일괄 적용하면 등급·제품 식별이 흐려질 수 있다.
6. **한 기체에 하나의 대표 이름을 쓴다.** 도감과 전투에서 서로 다른 별칭을 외우게 하지 않는다. 길어지는 이름은 UI 줄바꿈으로 검토하고, 보스의 ‘폭주’ 상태는 별도 표시할 수 있다.

## 보스와 공유할 네 기체 — 우선 권고

| 현재 이름 | 추천 이름 | 연결할 외형·역할 | 판단 |
| --- | --- | --- | --- |
| 볼트타이탄 | **불꽃 토스터** | 토스터 / 화염 | 제품과 공격 성격이 함께 드러남 |
| 궤도브레이커 | **회오리 선풍기** | 선풍기 / 바람·범위 | 친숙한 기기와 회전 원리가 연결됨. 흡입·밀치기 기능을 뜻하지 않음 |
| 플라즈마캐스터 | **번개 전자레인지** | 전자레인지 / 전격·연쇄 | 전격으로 개조한 가전이라는 인상을 줌. 실제 UI 길이 검토 필요 |
| 오비탈옵저버 | **광선 영사기** | 빔프로젝터 / 레이저·단일 | 한국어 제품명을 중심으로 기능을 표현. 현대적인 말맛을 더 원하면 ‘빔프로젝터’도 대안 |

기획팀은 선풍기에 ‘강풍 선풍기’, 영사기에 ‘빔프로젝터’를 대안으로 제안했다. 대장은 이번 한국어 친숙성 요청에 맞춰 위 표를 우선안으로 정리했다. 선호가 검증된 이름이라고 주장하지 않는다.

보스에도 토스터·선풍기·전자레인지·영사기라는 공통 명사를 유지한다. ‘폭주’ 상태, 벌어진 외장, 경고 부품과 보스 체력 표시로 구별한다. 아군만 어려운 고유명사로 바꿔 같은 기체라는 연결을 끊지 않는다.

**이 이름들은 앞서 제작한 가전 시안과 함께 적용할 후보다.** 현재 `zhang_fei`의 실제 대표 PNG는 토치 계열이므로, 그 그림을 그대로 두고 이름만 토스터로 먼저 바꾸지 않는다. 네 기체의 내부 ID·속성·재료·해금은 현재 값으로 추적한다.

## 적용 시점과 확인할 것

이번은 검토 요청이므로 `content.units[].name`은 변경하지 않았다. 보스 공유 네 기체는 원형 제작과 함께 이름을 맞춘다. 다른 장비형 후보는 확정 아트·공격 연출과 실제 소형 UI에서 함께 비교한다.

적용할 때는 표시명만 바꾸고 내부 ID/조합 재료/계정 해금/저장 기록을 유지한다. 튜토리얼 고정 문구·도감·재료 부족 표시·보스 이름·결과 안내·모바일 자산 계약의 이름을 함께 점검한다. 이름 교체 때문에 미구현 보호·소환 기능을 새로 추가하거나 유닛풀을 늘리지 않는다.

우선 확인할 질문은 그림을 처음 본 사람이 이름으로 물건을 짐작하는지, 이름만 보고 공격 속성을 크게 오해하지 않는지, 보스와 아군의 같은 원형을 알아보는지다. 현재 단계에서 자연스러움·재미·기억률을 수치로 검증했다고 말하지 않는다.

근거는 현재 콘텐츠와 [가전 보스 설계](../design/APPLIANCE_BOSSES.md), [기존 생활용품 방향](../plans/2026-09-21-household-robots-design.md)이다. 외부 게임의 이름·캐릭터는 가져오지 않았다.
