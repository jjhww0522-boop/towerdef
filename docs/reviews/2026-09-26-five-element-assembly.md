# 기본 5종과 단일·복합 조합 비교 — 2026-09-26

상태: 사용자와 논의할 설계 권고. 콘텐츠 `0.11.1-quick-start`의 유닛·조합·소환 확률은 수정하지 않았다. 기획·밸런스팀과 서버·전투시스템팀의 독립 검토를 종합한다. 실제 사람 플레이 검증은 없다.

사용자의 “처음에는 속성 5개”는 **화염·냉동·바람·전격·레이저 각각 기본 1종, 총 기본 5종**으로 해석했다. 속성 수와 각 속성 안의 유닛 종류 수는 별개다. 기존의 같은 속성 기본 여러 종을 모두 유지하면 소환 재료가 분산되는 문제는 남는다. 이전 4→6→9 기본 풀 제안은 비교 이력이며 이번 논의는 5종부터 출발한다.

## 권장 구조

**단일 조합을 기본 성장 경로로 유지하고, 3등급부터 소수의 선택형 복합 조합을 점진적으로 추가한다.** 첫 두 구역은 단일 조합만으로 통과할 수 있도록 설계한다. 기획팀은 새로운 시설 목표를 배우는 2스테이지와 겹치지 않게 복합식 소개를 3스테이지부터 시작할 것을 권했다. 정확한 해금 구역과 최종 수치는 검증 뒤 확정한다.

```text
A1 + A1 + A1 → A2                 첫 규칙
A2 + A2 + A2 → A3                 단일 계열의 집중 성장
A2 + A2 + B2 → AB3                나중에 여는 특화 분기 예시
```

위 표기에서 A/B는 서로 다른 속성의 가족, 숫자는 등급이다. AB3는 혼합 제작 계보를 나타내며 두 속성 피해·상태 효과를 모두 갖는다는 뜻은 아니다. 실제 능력은 별도로 정한다.

| 방식 | 강점 | 설계상 위험 | 판단 |
| --- | --- | --- | --- |
| 끝까지 동일 3기 | 규칙이 쉽고 성장 방향이 명확함 | 상위 재료 3→9→27기로 늘고 원하는 중복을 기다리는 비중이 커질 수 있음 | 기본 경로로 유지 가능. 자동으로 재미없다는 뜻은 아님 |
| 처음부터 다양한 복합식 | 남길 재료·목표 전환·역할 선택이 일찍 생김 | 짧은 입문 구간에 조합 암기와 정보 탐색이 겹침 | 난이도 1/1.5의 첫 두 구역에는 우선하지 않음 |
| 단일 기본 + 나중의 선택형 복합 | 쉬운 입문과 이후 빌드 선택을 함께 확보 | 혼합이 항상 더 강하면 단일이 함정이 됨 | 우선 검증할 권장안 |

복합식은 처음부터 모든 속성 쌍을 만들지 않고 2~3개로 비교한다. 같은 결과 유닛으로 가는 우회식보다 서로 다른 역할의 결과를 우선 설계한다. 단일은 주 역할의 집중 성능, 복합은 다른 상황에 대응하는 특화로 차이를 만들되 실제 화력·사거리·유틸 효과를 검증한다.

`A2+B2→AB3`는 기본 환산 6기, `A2×3→A3`는 9기다. 동일 등급이라는 이름만으로 같은 성능을 주면 혼합이 싸고 강한 선택이 될 수 있다. 첫 비교는 3재료끼리 맞추고, 같은 명목 비용도 획득 난도·버리는 공격 위치·실전 기여까지 같지는 않다는 점을 확인한다.

## 초반 목표와 재료 부담

첫 구역 최대 3분·난이도 1, 둘째 구역 4분·난이도 1.5를 유지한다. 첫 두 구역의 목표는 **2등급 몇 기를 만들어 역할의 차이를 경험하는 것**이다. 3등급 제작을 클리어 필수 조건으로 잡지 않는다. 상위 직뽑기 없이 같은 가족을 계속 3배 합성하면 2/3/4등급에는 기본 3/9/27기가 필요하며 소환비만 환산하면 60/180/540고철이다. 이는 필요한 재료의 명목 값이며 실제 총 지출이 아니다.

서버팀은 균등·독립 추첨에서 첫 삼중 중복 확률을 정확 계산했다. 중간 조립·판매·전투 수입·소환 시간은 없는 모델이다.

| 기본 풀 / 등급 가정 | 7회 안에 아무 기본 3기 | 10회 안에 아무 기본 3기 |
| --- | ---: | ---: |
| 5종 / 전부 기본 | 67.744% | 98.839% |
| 9종 / 전부 기본 | 29.821% | 67.978% |
| 5종 / 기본 93%, 나머지는 기본 중복에 기여하지 않음 | 58.228% | 94.342% |
| 9종 / 같은 93% 가정 | 24.724% | 59.139% |

상위 직뽑기는 자체 전투력이 있으므로 마지막 두 행의 나머지를 성장 실패율로 부르지 않는다. 다섯 종류만 기본으로 뽑을 때 특정 가족의 기본 9기까지 기대 뽑기는 45회다. 그동안 다른 가족도 쌓이므로 45×20을 그 한 유닛의 순수 제작비로 보면 안 된다.

첫 합성 가능성이 높아져도 **10칸 교착은 남는다**. 예를 들어 다섯 속성의 기본 각 1기와 2등급 각 1기는 총 10칸이며 동일 등급·가족 3기가 없다. 현재 판매는 탈출 수단이지만 손실이 있으므로, 실제 적용 전 만칸에서의 진행 가능성·재뽑기 부담·상위 도달 시간을 따로 확인한다. 복합식 몇 개만 추가한다고 모든 교착이 해소되는 것도 아니다.

## 업데이트와 구현 검토

- 신규 유닛은 해금되었다고 기존 초반 소환 풀에 자동으로 전부 넣지 않는다. 초기 구역의 공개된 5종 풀을 유지하거나 추후 출전 가족 선택 방식을 검토한다.
- 초반에는 5속성의 기존 역할을 명확히 한다. 같은 역할의 기본 유닛을 늘리는 것보다 먼저 성장 외형·공격 변화·상위 선택지를 완성한다. 신규 기본 전격의 연쇄 여부 등은 실제 능력에 맞춰 설명해야 한다.
- 조합은 선택한 유닛 창에서 결과·남길 자리·필요 수량과 소모할 재료를 확인한다. 혼합 해금 때 필요한 정보만 추가한다.
- 현재 서버와 콘텐츠 검증기는 동일 정의의 재료 3개를 처리할 수 있다. 실제 개체 ID는 서로 달라야 한다. 그래서 단순 데이터 한 줄 변경으로 끝난다는 뜻은 아니며, 가족/해금/소환/수치/훈련/UI/기존 기록의 연결을 함께 검증해야 한다.
- 확인 순서: 첫 조립까지의 시간, 막힌 만칸 빈도, 단일·혼합의 실전 기여, 3분/4분에서의 성장, 새 풀 해금 전후 비교. 봇 결과와 인간 체감은 구분한다.
