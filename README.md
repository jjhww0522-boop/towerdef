# Towerdef — 삼국지 운빨 디펜스 (가제)

아이폰을 우선 지원하는 **4인 협동** 모바일 랜덤 디펜스 게임을 개발하는 저장소입니다.
플레이어는 각자 자신의 라인을 방어하며, 별도의 공동 목표인 **스토리**에 유닛을 파견합니다.
랜덤으로 얻은 재료, 정해진 조합식, 태그별 강화 투자로 전력을 만들고 어려운 클리어에 도전합니다.

**현재는 브라우저에서 플레이할 수 있는 개발용 버전입니다.** 27종·18개 조합식, 4인 로컬 연습, 캐주얼 벡터 캐릭터·선택 유닛 진화 화면과 전투 연출을 구현했습니다. 자동 브라우저 4접속 및 HTTP 연결 장애 검증을 수행했습니다. 실제 사람의 소비자 테스트, 영구 진행, Unity 아트 이식과 아이폰 빌드는 아직 완료되지 않았습니다.

> 회사에서 이어갈 때는 [최신 인계 및 페르소나 토의](docs/LATEST_HANDOFF.md)를 먼저 읽으세요.

## 바로 실행하기

Node 22 이상에서:

```powershell
npm ci
npm test
npm run dev
```

브라우저에서 `http://127.0.0.1:7351`을 열고 **새 연습 시작**을 누릅니다. 같은 방 코드로 서로 다른 브라우저 프로필에서 최대 네 접속을 연결할 수 있습니다. 로컬 전용 서버이므로 외부 기기 접속은 제공하지 않습니다. Unity 경로는 [클라이언트 안내](docs/CLIENT_SETUP.md)를 따릅니다.

화면·애니메이션의 구현 범위와 남은 품질 관문은 [화면 품질 기록](docs/VISUAL_QUALITY.md), 검증 결과는 [반복 개발 결과](docs/ITERATION_RESULTS.md)에 정리했습니다.

- [개발 환경·프로토콜·검증 범위](docs/DEVELOPMENT.md)
- [이번 구현 계획](docs/IMPLEMENTATION_PLAN.md)
- [애니메이션 제작·에셋 출처](docs/ART_PIPELINE.md)

Unity 없이 서버 빌드와 자동 테스트는 실행할 수 있습니다.

## 집에서 이어가기

처음 내려받는 경우:

```powershell
git clone https://github.com/jjhww0522-boop/towerdef.git
cd towerdef
git status
```

이미 복제한 경우, 먼저 로컬 변경을 확인하고 `main`을 업데이트합니다.

```powershell
git status
git switch main
git pull --ff-only origin main
```

로컬 수정 때문에 전환이나 갱신이 실패하면 그 수정을 보존한 뒤 충돌을 해결합니다.
강제 초기화로 덮어쓰지 않습니다.

새로운 개발 세션에는 다음과 같이 요청하면 됩니다.

> AGENTS.md, docs/GAME_DESIGN.md, docs/HANDOFF.md를 읽고 현재 상태를 확인해줘.
> 합의한 게임 방향을 유지하면서 제작팀의 기본안을 바탕으로 자율적으로 개발을 이어가줘.
> 아직 확인되지 않은 환경·계정 정보는 추측하지 말고, 독립적으로 가능한 작업부터 진행해줘.

## 방향

- 개인 방어는 각자가 책임집니다. 동료가 내 라인의 적을 직접 제거하는 기능은 넣지 않습니다.
- 첫 완성본은 4인을 목표로 합니다. 8인과 그 이상은 사용자가 원하는 확장 방향이며, 부하·화면·매칭·협동 테스트 후 지원 범위를 정합니다.
- 협력은 스토리 파견과 공동 보상, 서로의 소환 결과를 보는 경험에 집중합니다.
- 기본 전력은 랜덤 재료와 확정 조합으로 만들며, 강한 유닛이 드물게 직접 소환되는 대박도 둡니다.
- 목표 장수를 완성하지 못하면 패배할 수 있습니다. 클리어를 보장하지 않습니다.
- 삼국지 소재를 바탕으로 유닛·조합·맵·대사·그림·음악을 독자적으로 제작합니다.

가제와 구체적인 콘텐츠는 출시 명칭이나 권리 검토가 완료된 결과물이 아닙니다.
시장 성공, 실기기 성능, 재미 검증 역시 아직 확인되지 않았습니다.
