# Pretendard

Bundled unmodified Pretendard Variable v1.3.9 for the Korean UI and Canvas text.
Family registered in CSS: `Pretendard`. License and copyright: [OFL.txt](OFL.txt).

Official source: https://github.com/orioncactus/pretendard/tree/v1.3.9

Font: `packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2`.
The font is served locally; game text does not depend on an external font CDN.

## Do Hyeon

Unmodified `DoHyeon-Regular.ttf`, acquired 2026-09-23 from the Google Fonts
[Do Hyeon directory](https://github.com/google/fonts/tree/main/ofl/dohyeon).
CSS family: `Do Hyeon`, weight 400. Used for headings and main actions;
body text and numbers continue to use Pretendard. No synthetic bold.
